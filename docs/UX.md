# 审核与编辑的交互设计（Opus 草案 r1）

用户的重点：**审核和编辑时的体验感**。评判标准是一次看完一集、把配词、读音、时间轴都改好，一共要多少操作：
剪切粘贴、点击、重复确认、句头句尾分家。界面围绕这件事设计，其他功能都为它服务。

## 1. 给用户的心智模型

- 一集 = 一列 **Group**。一个 Group = 一句（或几句）中文 + 对应的日文 + 它们的读音、时间。
- 日文是一条按原文顺序流动的“文字带”，Group 只是在带上切的分界；中文也是一样。
  **改配对 = 移动分界**。所以只要用分界操作，日文（和中文）永远不会被打乱顺序，用户不用担心。
- 隐藏的东西一定有标记：Group 上有“含 2 处未渲染语气词”“读音 ?×1”“只有日文”等小标签，点开就能看到、恢复。

## 2. 主窗口（沿用 Aegisub 的位置习惯）

```
┌───────────────────────────┬──────────────────────────────────────────┐
│ 视频（libmpv，实时显示     │ 音频波形：中文条 / 日文条，播放头、选区     │
│ 带振假名的当前工作字幕）    ├──────────────────────────────────────────┤
│                           │ Group 编辑区：上一组尾 ┆ 本组 ┆ 下一组头    │
│                           │   中文（可编辑）                           │
│                           │   日文（可编辑，上方实时显示振假名）         │
├───────────────────────────┴──────────────────────────────────────────┤
│ Group 列表：# │ 时间 │ 中文 │ 日文（带振假名） │ 标签（?、只有日文、语气词…）│
├──────────────────────────────────────────────────────────────────────┤
│ 原文面板（可停靠）：本组附近的原始日文 cue / 中文事件，原时间、cue 号、说话人  │
└──────────────────────────────────────────────────────────────────────┘
状态栏：播放时间 │ 第 n 组 │ 未确认 x │ 读音待定 y │ 后台：波形 80%（可取消）
```

所有面板都是可停靠窗口，可以拖动、关闭、恢复默认布局；高 DPI 下按系统缩放。

## 3. 审片流程（一遍完成）

| 操作 | 默认键 | 说明 |
|---|---|---|
| 播放/暂停 | Space | 视频、波形、列表同步；列表自动跟随当前 Group |
| 重播本组 | R | 从本组开始前 0.5 秒播到结束后 0.3 秒 |
| **确认并播放下一组** | Enter | 本组标记 ✓（重新对齐时锁定），跳到下一个未确认的组并播放。正常情况下一路按 Enter 看完 |
| 只确认不移动 | Shift+Enter | |
| 上一组/下一组 | ↑ / ↓（列表里）、PgUp/PgDn | |
| 撤销/重做 | Ctrl+Z / Ctrl+Y | 文字、时间、配对、读音、确认都能撤销 |
| 保存 | Ctrl+S | 另有自动保存和崩溃恢复 |

改动立刻生效，视频里的字幕（含振假名）在 0.3 秒左右更新；排版还在计算时状态栏会显示，不会把旧结果当新结果。

## 4. 配词（最常用的修正）

### 4.1 移动分界（日文永远保持原文顺序）

| 操作 | 默认键 | 例子（交叉评测里 Claude 版的错误） |
|---|---|---|
| 本组开头一段 → 上一组 | Alt+↑ | |
| 本组结尾一段 → 下一组 | Alt+↓ | 例 9：「まだ とぼけるおつもり〜？ 七実様」→ 把「七実様」送到下一组 |
| 拿回上一组结尾一段 | Alt+Shift+↑ | 例 10：下一组按一次，拿回「え〜？ 私」 |
| 拿回下一组开头一段 | Alt+Shift+↓ | |
| 中文的同样操作 | 加 Ctrl | 很少用到 |

- “一段”= 原文里的一个短语（空格或句末标点分开的地方）。人名、固定短语、词库锁定的词不会被切开。
- 要在字中间切：在日文编辑框里放光标，Ctrl+Shift+↓“光标后面移到下一组”，Ctrl+Shift+↑“光标前面移到上一组”。
- 鼠标：列表里两组之间的日文分界有一个小把手，可以拖；也可以把一段拖到相邻的组。
- 跨过不相邻的组移动会破坏顺序，需要明确确认，并在两组上留下“顺序例外”标记。

### 4.2 合并、拆分、链接

| 操作 | 默认键 |
|---|---|
| 与下一组合并（中文、日文都保留，按原顺序） | Ctrl+J |
| 拆分本组（按日文光标和中文光标/换行位置） | Ctrl+K |
| 解除配对（中文、日文各自成组，顺序不变） | Ctrl+U |
| 删除：只删这一行 / 删整个 Group | Delete 时弹出选择（可记住选择） |

### 4.3 语序相反、拿不准的地方

算法遇到中文 A2→A1、日文 A1→A2 时不会交换日文，而是给出“两行中文 + 一句日文”的多行 Group（标签：多行组）。
用户可以接受（日文在两行中文期间持续显示），或者用 Ctrl+K 按自己的判断拆开。

## 5. 读音

- 日文编辑框里，振假名直接显示在字的上方。待定的读音用琥珀色虚线标出；Group 列表上显示 `?×n`。
- **点一下汉字**（或选中后按 F2）弹出小面板：
  - 候选读音（数字键 1–9 直接选，例如 私：1 わたし 2 わたくし 3 あたし）；
  - 输入框：直接输假名，或者输罗马字（`watakushi` 自动变 わたくし），**不用切换输入法**；
  - 范围：只改这里 ／ 本集规则 ／ 项目规则（默认“只改这里”）；
  - 显示读音来源（项目词库 / 人物规则 / 原料自带 / 自动 / 配音建议）；被规则覆盖时显示“被规则 X 覆盖”，可以选“本处例外”；
  - “不标注”“调整注音范围（合并/拆开）”。
- Tab / Shift+Tab：在本组的待定读音之间跳；Ctrl+Enter：接受本组所有建议。
- 同一行两个「私」各自独立，因为注音挂在具体的字上，不是按字符串查找。

## 6. 时间轴

- 波形上画出当前组和前后组：中文条在上、日文条在下。
- 拖动条的中间 = 平移整个 Group（中文、日文、振假名、K 轴一起，保持相对偏移）；拖动边缘 = 只改这个成员的开始/结束。
- 工具栏开关“仅当前成员”：打开后键盘微调只作用于当前成员。
- 键盘：`[` `]` 开始时间 −/+ 一帧，`Shift+[` `Shift+]` 结束时间；按住 Alt 改为 10 毫秒步长。
- 鼠标在波形上框选一段 → `S` 设为开始、`E` 设为结束（作用于当前 Group 或当前成员）。
- 改边界和拉伸是两个不同的操作；拉伸 K 轴必须明确选择，不会静默缩放。

## 7. 语气词

- 默认“保留全部语气词”：语气词就是普通文字，不想要就删（删除会被记住，刷新不会复活，可以撤销）。
- 简洁模式：独立、中文没有翻译的语气词不渲染，Group 上显示“含 n 处未渲染语气词”，点开逐条“恢复显示”。

## 8. 原文面板

- 显示本组附近的原始日文 cue（cue 号、原时间、说话人标签、完整原文）和中文事件；本组用到的部分高亮，
  说话人标签、≪≫ 等结构化元数据灰色显示，未渲染的语气词有标记。
- 点原文里的一段 → 跳到包含它的 Group。

## 9. 不让用户碰代码

正常流程里不需要输入 ASS 标签、`@读音`、`{@fx}`。字体、样式、位置、特效通过工具栏和属性面板设置。
“ASS 源码”是单独的高级模式，默认关闭；原文里的 ASS 标签在普通模式下也不会丢。

## 10. 第一阶段做到哪里

第一阶段交付第 2–4、6 节和第 3 节的全部快捷键、第 8 节的原文面板；读音先做“点击 → 候选 → 只改这里”，
本集/项目规则、人物与词库编辑器、批量样式在第二阶段。所有快捷键以后可以在设置里改。
