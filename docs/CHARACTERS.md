# D 人物（说话人与工程级人物表）— 设计

状态：Claude 2026-10-04 定（用户：C、D、F 依次做）。界面文字以本文件为准（「」里照抄）。
来源：REQUIREMENTS 十一（人物）、PLAN-1b D。

## 1. 现在的情况
- 每一行记着原字幕的说话人标签（`member.speaker.label`，例如「城一郎」），还没有和“人物”连起来（`character` 都是空的）。
- 旧的 `dict/characters.tsv`（日文名、假名、中文名、别名、私的读法、备注）只用于读音：人名当固定词、按说话人标签选「私」的读法。

## 2. 数据：工程的 `dict/characters.json`
- 每个人物：稳定 ID（`chr_…`），**各语言的名字**（见 2.1）、**别名**（字幕标签和台词里的其他叫法：ソーマ / 創真くん 去掉敬称后的 創真）、
  **自称**（见 2.2）、**人设**（自称、对别人的称呼、口癖、语气/敬语、备注；中日各一份）、可选的默认样式。

### 2.0 两种名字分开（用户 2026-10-05）
- **真实姓名**（姓 + 名 + 各自读音）：主要用途是让以后各集自动加振假名/拼音时，**人名切分和读音更准**（以及「私」等自称读得对，见 2.2）。
- **字幕名字栏里写的名字**（导出 ASS 的 Name）：每种语言单独一项，可以选由真实姓名拼出（全名 / 姓 / 名），也可以**自己随便写**（例「创真」「Soma」），和真实姓名互不影响。
- 人物详情对话框把这两块分开显示：上面「真实姓名（用于读音）」，下面「字幕名字栏」。

### 2.1 名字按语言分成「姓」「名」，各带读音（用户 2026-10-04 的建议）
- 每种语言一组：「姓」「名」「姓的读音」「名的读音」「顺序」「连接符」。读音：日语 = 假名（振假名），中文 = 拼音，其他语言没有读音。
  只有一个名字的（めぐみん / 惠惠）只填「名」。
- 例：
  - 幸平創真：日语 姓「幸平」(ゆきひら) 名「創真」(そうま)，姓在前、不加连接符；简中 姓「幸平」(xìng píng) 名「创真」(chuàng zhēn)。
  - めぐみん：日语 名「めぐみん」；简中 名「惠惠」(huì huì)。
  - Sheldon Cooper：英语 名「Sheldon」姓「Cooper」，名在前、空格；简中 名「谢尔顿」姓「库珀」，名在前、「·」；日语 名「シェルドン」姓「クーパー」，名在前、「・」。
- 默认按语言数据表（LANGUAGES 3.5）：日语、中文、韩语 姓在前、不加连接符；越南语 姓在前、空格；其他语言 名在前、空格。
  外国人名在日语/中文里常用「・」「·」，可以按人物改。读音一栏按这种语言的注音方式显示（日语假名、中文拼音；没有注音方式的语言不显示）。
- 名字的各部分（连同读音）自动成为读音词库里的固定词：日文里单独出现「幸平」也会注 ゆきひら；中文名的多音字按这里的拼音（例：单(shàn)）。
- **写进 ASS 名字栏（Name）的方式**（导出选项，按这一行的语言拼）：「常用称呼」（默认）「全名」「只写姓」「只写名」「原标签」（原字幕里的说话人标签，和以前一样）。
  「常用称呼」每个人物每种语言可以单独选（全名 / 姓 / 名 / 自己填），例：幸平創真 常用「幸平」，めぐみん 常用「めぐみん」。

### 2.2 自称（私 / 僕 / 俺 …）
- 日语原声工程默认「私 → わたし」（全部），已有全范围读法照旧；打开工程补一次，删除后在人物额外数据中记住，不再补回。新建、TSV 转换及 Bangumi 新人物同样适用。
- 每个人物可以有几条：「写法」「读法」「范围」（全部／季／集，季和集填编号；句范围仅从自称检查产生，只读显示集、组号、前 12 字；旧句编号找不到时显示「某一句（找不到了）」），例：私 → わたくし；某一集里私 → わたし。
- 读音引擎按说话人用它（2.1 和第 4 节），「自称检查」（第 7 节）也用它。
- **群众身份**：「生徒A」「男1」这类标签可以标成群众（不是人物，不套自称规则）。
- **待确认的标签**：合并时遇到人物表里没有的标签，记成待确认（附出现次数、例句、出现在哪几集），**不会自动变成人物，也不会自动并到别人名下**。
- 旧工程第一次打开时，如果有 `characters.tsv` 而没有 `characters.json`，自动转换一次（`characters.tsv` 保留不动）。

## 3. 说话人怎么连到人物
- 合并、重新分析时：标签和某个人物的名字/别名**完全一样**才自动连上；其他的进待确认。不按读音或相似度猜。
- 原字幕的标签永远保留（`label`），连到人物只是多记一个 `character`。
- 同一组的中日文默认是同一个人（「整组同一人」）；可以对一行单独指定（两人同一 cue 的情况）。
- 你手动指定的说话人不会被重新合并或刷新覆盖。整集重新合并保不住时就不合并，提示：
  「重新合并会把不同的人工说话人合到一行；请保留现有配对」/「重新合并无法保留部分人工说话人；请保留现有配对」。

## 4. 用在哪里
- **读音**：人物的名字是固定词；说话人是这个人物时，「私」等自称按他的读法（有季/集/句的例外时，例外优先）。改了人物表，只刷新自动读音。
- **导出**：「名字栏（Name）」写说话人的名字，**按这一行的语言**、按 2.1 的写法（全名 / 只写姓 / 只写名 / 常用称呼）拼出来
  （中文行写中文名，日文行写日文名；没有这种语言的名字时用相近的（简中↔繁中），再没有就写原来的标签）。和现在一样是导出选项，写法在导出对话框里选，默认「常用称呼」。
- **审议包**：人物表附上人设（自称、称呼、口癖、语气、备注），方便大模型检查用词是否符合人设。

## 5. 界面
### 5.1 「人物」面板（视图菜单「人物」，停靠窗口，和原文面板一样可以开关）
- 上方搜索框（提示「搜索名字、别名」），下面人物表：每种工程语言一列全名（例「幸平創真（ゆきひら そうま）」「幸平创真」），再加「别名」「自称」「备注」；
  别名和备注可以直接在表里改，名字和自称在「人物详情」里改（双击一行打开）。
  按钮「新建人物」「删除人物」「合并到…」（把一个人物并到另一个，别名合在一起，各行的说话人改过去；先确认）「人物详情…」。
- 下方「待确认的标签（{n}）」：每个标签一行「{标签} ×{次数}　{例句}」，按钮「新建人物」「归到人物…」「标为群众」「不是人物」（例如效果音、语气说明被认成了标签）。
  标签正好是**某一个**人物的姓、名或别名的一部分时（例：标签「アルベール」、人物「アルベール・ド・モルセール子爵」），这一行加一句「可能是：{人物}」和按钮「归到 {人物}」——
  只是建议，点了才归（并把标签加进这个人物的别名）；符合的人物不止一个时不提示。
- 删除人物前确认：「删除人物「{名字}」？{n} 行的说话人会变回原来的标签。」

### 5.2 人物详情对话框（标题「人物：{名字}」）
- 「名字」：每种工程语言一组（可以「加一种语言」）：「姓」「名」「姓的读音」「名的读音」（日语=假名，中文=拼音，其他语言不显示）、
  「顺序：姓在前 / 名在前」「连接符：无 / 空格 / ・ / ·」「常用称呼：全名 / 姓 / 名 / 自己填 {框}」，下面实时显示拼出来的全名和常用称呼。
- 「别名」：一行一个。
- 「自称」表：「写法」「读法」「范围」（全部／季／集；句范围只读）。
- 「人设」：「自称（说明）」「对别人的称呼」「口癖」「语气 / 敬语」「备注（日语）」「备注（{翻译语言}）」。
- 按钮「确定」「取消」「帮助」。改了名字或自称，自动读音跟着刷新（你确认过的不动）。

### 5.3 说话人
- 组编辑区每一行前面有说话人下拉框：可以打字搜索（名字、别名），最近用过的在前面；选项末尾「（原标签：{label}）」「群众…」「新建人物…」。
- 勾选「整组同一人」时改一行就改整组。改说话人一步撤销。
- 列表新增一列「说话人」（显示人物名；没连上的显示原标签并带“?”）。

### 5.4 观剧模式里显示说话人（用户 2026-10-04）
- 视图菜单「观剧模式显示说话人」（开关，默认关；记住）。打开后 F10/F11 里**每一组只显示一次**说话人名字，写成「{名字}：」，
  **紧接在翻译字幕那一行的左边**（用户 2026-10-04）：例「幸平创真：太好了」——「太好了」仍在原来的位置（默认对齐时仍居中），名字只是接在它左边，
  同一基线、同样字号；翻译有好几行时接在第一行左边；这一组没有翻译行时接在原声行左边；左边放不下时缩小字号，仍放不下就截短名字。
  **只在观剧模式的画面上显示，不进导出、不改字幕、不影响字幕位置**。
- 显示哪一种语言的说话人：同一个菜单下「说话人按：原声 / 翻译」（默认原声）；名字按那种语言的常用称呼（2.1）。
  这一组那种语言的行没连到人物时，用另一种语言的行；都没有时显示红色的「? 说话人」告警（原标签有内容时写「? {原标签}」）。
  群众显示灰色「群众」；标成“不是人物”的不显示。
- 仅对白组内的对白／顶部对白／同时说话需要说话人；歌曲、屏幕字、说明、注释、制作名单不显示告警或列表问号。一个源文件的 Dialogue 行里 Name 出现 ≥20 行且占 ≥50% 时视为文件标签，忽略其显示和待确认，保留原料；人工指定不受影响。
- **点这个名字或告警**：暂停，在它旁边打开「说话人」小窗（可以获得焦点的工具窗口，输入法可用）：搜索框（名字、别名）+ 列表（最近用过的在前），
  「整组同一人」默认勾选；「新建人物…」（预填原标签，打开人物详情）、「群众」、「清除（回到原标签）」；选中即生效，一步撤销；Esc 关闭。
- 只对已经显示出来的字幕起作用；字幕位置变了（拖动、自由变换）名字跟着走。

## 5b. 没有说话人标签时：找出台词里的人名（用户 2026-10-04）
- 原字幕没有说话人标签（很多 ASS/SRT 就是这样）时，至少把**台词里出现的人名**找出来：
  - 日语：用分词器（Sudachi）的“人名”词性（姓 / 名），加上人物表里已有的名字和别名；
  - 英语：句中大写开头、反复出现的词（不在句首的）；
  - 中文：日中配对的组里，日语人名出现的那些组的中文行里反复一起出现的 2–4 个字，作为“中文译名建议”（只建议）。
- 人物面板加一栏「台词里的人名（{n}）」：每个一行「{名字}（{读音}）×{次数}　{例句}」，按钮「新建人物」「加到人物…」（作为别名或补上这种语言的名字）「不是人名」。
  新建时姓名按分词器拆好的姓/名预填，读音预填；中文译名建议预填到翻译语言的名字里（都可以改）。
- 只是列出来、预填，**不自动建人物、不自动改任何台词**；“不是人名”记住，以后不再列出。

## 5c. 从 Bangumi 导入人物（用户 2026-10-04）
- 人物面板按钮「从 Bangumi 导入…」：粘贴作品链接（例 `本地配置路径`）或编号。**只在点这个按钮时联网**。
- 读取：作品的人物列表（日文名、主角/配角/客串、声优），再逐个读人物资料里的「简体中文名」「罗马字」「假名」等（有就用）。请求之间稍等一下，不给网站添麻烦。
- 预览表（标题「从 Bangumi 导入：{作品名}」）：每个人物一行，勾选框 +「日语名」「中文名」「罗马字」「角色」「声优」「对应」
  （和人物表里已有的人物按日文名/别名完全一致时写「更新：{名字}」，否则「新建」；也可以手动改对应的人物或选「不导入」）。
  选项「中文名转为繁体」（工程的翻译是繁中时默认勾选；用 OpenCC 按词转换）；只导入主角、配角（客串默认不勾）。
- 写入时：日文名按分词器拆成姓/名并带假名读音（片假名外国名按「・」拆、名在前），罗马字用来核对拆法；拆不准的整个放在「名」里，在预览里可以改。
  中文名写进翻译语言的名字（姓名拆法跟日文名对应；拆不准就整个放在「名」里）。已有人物只**补空着的字段**，不覆盖你改过的。导入一步完成，可以撤销（人物表文件恢复）。
- 无任何可显示姓名的行标红「缺名字」，默认不勾选；勾选提示「这一行没有名字，请先填名字」，导入再次检查。
- 不导入图片、简介等；没有中文名的人物只导入日文名。网络出错、链接不对时：「无法从 Bangumi 读取：{原因}」。

## 7. 自称检查（用户 2026-10-04：私 的 watashi / watakushi）
- 集菜单「检查自称（私 的读法）…」：对说话人已连到人物、而且人物有「自称」的日语行，找出自称写法（私 / 僕 / 俺 …）的每一次出现，
  比较这一处的振假名和人物的自称读法（按季/集/句的范围）。
- 对话框「自称检查」：列出不一致的「{时间}　{说话人}：{句子}　私({现在}) → 应为 {读法}」；说话人不明但句子里有「私」的另列「说话人不明」。
- 每一行：「试听」（跳到这一句播放——有的角色看场合用 わたし / わたくし，听了再决定）、「改成 {读法}」（改这一处的读音，确认过）、
  「只保留这一句」（确认读音并记为句例外）、「这一集都这样读」（确认并记为集例外）。双击一行跳到这一组。
- 全部一致时：「自称都和人物表一致。」 每次修改一步撤销。

## 6. 验收
- 旧 `characters.tsv` 转换后读音结果不变（食戟测试工程：人名、「私」的读法一致）。
- 标签完全一致才自动连；其他进待确认；群众和“不是人物”不再出现在待确认里。
- 导出名字栏按语言；指定说话人保存重开不变、一步撤销；重新合并不覆盖手动指定。
