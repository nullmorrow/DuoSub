# 旁注（在字上任意位置加注释文字）（用户 2026-10-07）

本文件是界面文字和规则的依据（`「」` 里照抄）。分批：G1 核心（解析、定位、预览/导出、和振假名的关系、错误提示）；G2 编辑器输入与说明书。

## 1. 背景
- 有些动画“说的”和“写的”不同（例：台词「你這個低等生物」，画面上「低等生物」上方写着「渦蟲」；原声行「プラナリア」）。
  用户以前用 Aegisub + Python 脚本：在行里写 `{CalUP:低等生物}`，脚本算出「低等生物」的九宫格 8 号点坐标，再手动加一个独立的字块。
- 旧版命令行工具已有旁注（`src/subkit/gloss.py`，`{@注:校庭=ガーデン}`，只放在上方，接在旧的 `workfile.py` 流程里）；现在的编辑器、预览、导出（`core/export.py`）都没有接上。数据模型里注音类型已有 "gloss"。
- 这次把旁注接进现在的程序，并加位置、距离、字体、字号、颜色。

## 2. 写法（写在台词文字里，翻译行、原文行都可以）
```
{@注:被注的字=注释文字}
{@注:被注的字=注释文字;位置;距离;font=字体;size=字号;color=#RRGGBB}
```
- 别名：`{@注:…}`、`{@g:…}`、`{@gloss:…}`；冒号、分号、等号全角半角都认。
- 被注的字：这一行里可见文字中的一段；同一行出现多次时取离这个标记最近的那一个（标记前优先，同距离取前面的）。留空（`{@注:=第一话}`）= 注在整行上。
- 位置：九宫格 1–9（小键盘方位），相对于被注那段字的外框：8 正上方（默认）、2 正下方、4 左侧、6 右侧、7/9/1/3 四角、5 正中。
- 距离：注释和被注字外框之间的距离，单位是视频画面的像素（按 PlayRes），可为负数，默认 0。
- 可选项（任意顺序，可省略）：
  - `font=` 字体名（原样使用；没装时照“检查字体”报告）。省略 = 跟随被注那段字实际用的字体（含行内 `\fn`）。
  - `size=` 字号（数字，按 PlayRes）。省略 = 被注那段字实际字号的 50%。
  - `color=#RRGGBB` 主颜色。省略 = 跟随被注字的主颜色。描边、阴影、粗体、斜体跟随被注字；描边粗细按字号比例缩小。
- 兼容旧写法：`{@注:目标=文字,80}`（逗号后的数字 = 横向缩放 %）。
- 注释文字原样显示：不转假名、不做繁简转换、不注音，可以是中文、日文、英文或混合。

## 3. 显示和导出
- **对齐方式（Claude 2026-10-07 更正）**：位置说的是旁注在被注字的哪一边，事件用**相反方向**的 `\an` 对齐，这样旁注从锚点往外长、不会叠在被注字上：8→`\an2`、2→`\an8`、4→`\an6`、6→`\an4`、7→`\an3`、9→`\an1`、1→`\an9`、3→`\an7`、5→`\an5`。距离按**墨迹**算（和振假名一样：用旁注样式实测的墨迹上下沿/左右沿补偿行高和字边距）；距离 0 = 两者墨迹之间留和振假名相同的间隙（工程设置 `ruby.gap`，默认 2 像素），正数离得更远，负数靠得更近。上方旁注和被注字的振假名不会同时出现（见下），所以不需要再避让振假名。
- 每个旁注导出为一个独立的 Dialogue 事件：时间同所在行；样式用 `<原样式>.Gloss`（没有就从原样式派生：字号 50%、其他相同）；上述反向 `\an` + `\pos(x,y)`，
  x、y 由被注字的**实测**外框（和振假名一样用 libass 测量）按位置和距离算出（8 号 = 外框上边中点再往上「距离」；2 = 下边中点往下；4 = 左边中点往左；6 = 右边中点往右；角同理；5 = 中心）。
- 所在行有 `\pos`/`\move`/对齐/边距/缩放/旋转时跟着走（和振假名的跟随规则一致：移动时用同样的 `\move`，旋转时用同样的 `\org`/`\frz`）。
- 所在行有淡入淡出（`\fad`/`\fade`）时旁注一起淡入淡出。
- 行里的 `{@注:…}` 标记本身不出现在导出文字里（它是私有标记，导出时去掉）。
- 日文行：旁注在上方（7/8/9）时，被注的那段字不再加振假名（已有的读音保留在数据里，只是不显示/不导出）；旁注在其他位置时振假名照常。
- 旁注不参与振假名的碰撞排版，位置以用户写的为准；和其他东西重叠由用户自己调距离。
- 预览（编辑模式视频、F10/F11）和导出都显示旁注；F10/F11 里点旁注不做任何事（不支持右键、拖动）。
- 卡拉 OK 特效生成的逐字事件不带旁注；有特效的歌词行，旁注作为一个静态事件跟着整行时间显示。

## 4. 写错时
- 以下情况这条旁注不显示，导出前检查和「检查」报告里列出：「旁注写法有误：{原标记}（{原因}）」
  原因：「找不到被注的字「{目标}」」「位置要写 1–9」「距离要是数字」「字号要是正数」「颜色要写成 #RRGGBB」「不认识的选项「{名}」」。
- 一行可以有多个旁注；同一段字可以有多个旁注（不同位置）。

## 5. 编辑器（G2）
- 在组编辑区翻译、原文的输入框里直接打 `{@注:…}`：保存为隐藏的标记（和其他行内 ASS 标签一样是标签段，不算可见文字，不影响读音/拼音/配对）；输入框里以灰色显示原样文字，可以直接修改、删除，一步撤销。
- 写在原文行时，注释文字不进读音弹窗，也不会被转成假名。
- 说明书新增一节「旁注」（锚点 `gloss`）：写法、九宫格示意、可选项表、三个例子（上方中文注释、日文汉字上叠英文、整行注释）、和振假名的关系、写错时的提示；「格式与 ASS 标签」一节加一句指向它；快捷键一览不变；版本记录。
