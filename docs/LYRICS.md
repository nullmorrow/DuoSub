# 歌词：补另一种语言、歌词对应、只打假名、英文按音节、导入旧版 OPED 资料

状态：设计（Claude，2026-10-05），来自用户第一轮 review。实现分三批：L1 补上另一种语言、L2 歌词对应与英文按音节、L3 导入旧版 OPED 资料。
本文件是界面文字的依据（`「」` 里照抄，`{}` 是要填的值；`{原声}` `{翻译}` 用工程的语言名，例如「原声（日语）」「翻译（繁中）」）。

## 0. 为什么要做

- Netflix 等 CC 字幕不收歌词，歌曲组常常只有翻译歌词，没有日文原文，也就没有振假名，没法按以前的方式打 K 轴。
- 用户以前的做法（`本地配置路径` 的 OPED.txt、OPED-DB、各集定稿里的「K轴」注释行）：
  **只给假名一行打拍**，再写一行对应表 `KaraOKMapping:在（ひ）陽（か）光（り）映照的（さす）校（ガー）庭（デン）…`，
  脚本按对应表算出日文原文（汉字块）和翻译的时间。
- 不只是歌曲：任何组缺日文或缺中文，都要能补上。

## 1. 补上另一种语言（L1）

### 1.1 规则
- 补上的文字是**用户插入的文字**（有自己的身份，不冒充来源字幕），可以撤销、可以删除；来源字幕不变。
- 时间取这一组已有那一行的开始和结束；样式取模板里这一类组（对白 / 歌曲）这一种语言的样式；角色跟组的类别（歌曲组 → 歌词）。
- 补上日文后自动生成振假名、补上中文后按设置生成拼音，和导入的字幕一样处理（自动读音、可以改）。
- 一次补上（不管几组）是一步撤销，撤销记录「补上{原声}」/「补上{翻译}」。

### 1.2 入口
- 列表右键：「补上{原声}…」「补上{翻译}…」。选中的组都已经有这种语言时灰掉：「（选中的组都已经有{原声}）」。
- 选中一组时：弹出小窗「补上{原声}」，一个输入框（输入法可用，Tool 窗口），按 Enter 或「补上」完成。
- 选中多组时：弹出「补上{原声}」表格，每组一行：「时间」「{翻译}」（已有的那一行，只读）「{原声}（输入）」。
  - 可以一行一行填；也可以点「从剪贴板粘贴」或在第一格 Ctrl+V 粘贴多行文字：按顺序一行填一格；空行跳过；行数不一样时提示
    「粘贴了 {a} 行，选中了 {b} 组：多的没有用 / 少的空着」。
  - 已经有这种语言的组不列出，表格上方写「{n} 组已经有{原声}，不列出」。
  - 按钮「补上」「取消」「帮助」。留空的行不补。
- 组编辑区：缺这种语言时显示一个空的输入行，占位文字「这一组没有{原声}，在这里输入后按 Enter 补上」。
- 观剧模式：选中的组缺这种语言时，在画面上那种语言本来的位置显示一个小按钮「＋ 补上{原声}」，点了打开同样的小输入窗。
  （双击空白处仍是退出观剧模式，不改。）

## 2. 歌词对应：翻译拍跟着原声拍走（L2）

### 2.1 概念
- 原声歌词按假名打拍（现在就是：原声拍 = 读音里的音节）；汉字块的时间由它的假名拍合起来（现在就是）。
- **对应**：把翻译歌词切成几段，每段对应原声里连续的几拍。翻译这一段从第一拍开始唱到最后一拍结束。
- 实现用现有的“翻译拍吸附到原声拍”：应用对应时，把翻译拍合并成这些段，每段的开头吸附到对应第一拍的开头、结尾吸附到最后一拍的结尾。
  以后改原声拍，翻译拍跟着动（现有行为）。
- 所以只给原声一行打拍就够了：汉字块和翻译都自动。

### 2.2 对应的写法（和以前的 KaraOKMapping 一样）
- `翻译的一段（原声的几拍）翻译的下一段（原声的几拍）…`，例：`在（ひ）陽（か）光（り）映照的（さす）校（ガー）庭（デン）握（て）著（を）彼（と）此（り）的（あ）雙手（い）`
- 括号全角半角都可以。括号里写这几拍唱的假名（就是 K 条上原声那一行显示的字），连起来要和这一行全部原声拍一致（空格不算）。
- 括号外的翻译段连起来要和翻译这一行的文字一致（空格、标点不算，跟在前一段后面）。
- 英文段可以一个词对应几拍，也可以一拍对应几个词。

### 2.3 「歌词对应」窗口
- K 轴工具条加按钮「对应…」：当前是歌曲组、原声和翻译都有文字时可用；否则灰掉写原因「（这一组没有{原声}）」「（这一组没有{翻译}）」「（不是歌曲）」。
- 窗口标题「歌词对应」；表格一行一组，范围是这一首歌（同一首歌的规则见 KARAOKE_FX：同类别、间隔不超过 15 秒），当前组选中：
  - 列：「时间」「{原声}拍」（拍与拍之间用「|」隔开，例 `ひ|か|り|さ|す|ガー|デン`）「对应（可以直接改）」「状态」。
  - 状态：对上时「✓」；不对时红字说明：「括号里的假名和原声拍对不上：第 {n} 拍应该是「{假名}」」「翻译文字对不上：多了「{字}」/ 少了「{字}」」「括号不成对」「有一段没有对应任何拍」。
  - 已经对应过的行显示现在的对应；没有对应的行显示自动建议（灰色，改动或点「采用」后变黑）。
- 按钮：「自动对应」（只改选中的行）「试听这一行」「应用」「取消」「帮助」。
  - 自动对应：按字数比例把翻译分给原声拍，每段至少一拍；英文按词。只是起点，需要用户检查。
- 应用：对上的行全部应用，一步撤销「歌词对应」；有对不上的行时先提示「{n} 行还没对上，这些行不改。继续吗？」。
- 应用后翻译行原来自己打的拍被替换为吸附的段；之前拖过、吸附过的翻译拍以这次的对应为准。

### 2.4 只打假名一行
- 刷剧连打（按住 K）在歌曲组里默认只打原声行；原声行有对应时，翻译跟着走，不需要再打翻译。
- 这一组没有原声时照旧打翻译行。

## 3. 英文按音节拆拍（L2）

- 现在英文一词一拍。K 轴工具条加按钮「英文按音节拆开」：当前行有两个以上音节的英文词时可用，否则灰掉「（这一行没有能拆的英文词）」。
- 点一下，这一行（原声或翻译里有英文的那行，两行都有就两行）每个多音节英文词按音节拆成几拍（例 `rev|o|lu|tion`），一步撤销「英文按音节拆开」。
  已经打过的拍按比例分给拆出来的几拍（标为占位，等重打或拖动）。
- 拆得不对用现有的 Ctrl+点字间 / 拍界 拆开或合并。
- 音节用断字词典（Pyphen，en_US）；装不上时用简单的元音规则。写进 THIRD_PARTY。

## 4. 导入旧版 OPED 资料（L3）

### 4.1 入口和规则
- 「重复段落库」窗口加按钮「导入旧版 OPED 资料…」。只读旧文件，不改它们；导入的结果是库里的重复段落，以后每集用「查找并套用重复段落」套用。
- 由用户自己选文件导入（程序不自动去找）。

### 4.2 认得的旧格式
1. **「K轴」注释行**（各集定稿 .ass 里）：`{\kf7}い{\kf19}さ…{\kf0}\N{KaraOKMapping:…}{CNOrigin:…,JPOrigin:…,KanaOrigin:…}`。
   带来：原声歌词（JPOrigin）、翻译歌词（CNOrigin）、整行假名（KanaOrigin）、假名拍的时间、对应表。
2. **分行的歌词**（OPED.txt、定稿 .ass）：样式名以 `JP` / `JPOPED` 结尾的是原声歌词，`CN` / `CNOPED` 结尾的是翻译歌词（可能带 `\kf`）；
   「振假名」注释行 `潔く（いさぎよく,75） 生き（いき）` 给读音（逗号后的数字是旧的缩放，忽略）；「K轴测试」行给假名拍。
3. **OPED-DB 的 .song**（CNOPED / JPOPED / FuriganaOPED 行）和同名的 .wav（音频）。.npz 是旧版本的音频特征，不用。
- 同一句同时有几种来源时，以「K轴」注释行为准，其次分行歌词。
- 读音：优先用「振假名」行；没有时用原声文字和整行假名（KanaOrigin）对齐出每个汉字块的读音（例 校庭 → ガーデン）。导入的读音算**你确认过的**。
4. **歌词块**（新写法，见 4.4）：.txt 文件，或在导入窗口里直接粘贴。
- 假名拍算“歌曲记忆”拍（打过的拍）。对应表变成翻译的吸附（第 2 节）。

### 4.3 「导入旧版 OPED 资料」窗口
- 「歌词文件」：可以选几个（.ass .txt .song）。
- 「音频」：用来在每集里找这首歌。选项「同目录同名的 .wav（OPED-DB）」「这一集的视频（歌词文件就是这一集的字幕时）」「选一个视频或音频文件…」；
  找不到音频的歌照样导入歌词，但写「没有音频，不能自动查找，只能手动套用」。
- 读完后列出认出的每首歌（按同一首歌的规则分开）：
  - 列：「导入」（勾）「名称」（可改）「类别」（片头曲 OP / 片尾曲 ED / 插曲，可改；名字里有 OP/ED 时预选）「版本」（可改）
    「行数」「时长」「读音」（「{n} 处」）「K 轴」（「{n} 拍」/「没有」）「对应」（「{n} 行」/「没有」）「音频」（「有」/「没有」）。
  - 名称默认：样式名去掉 CN/JP 后的部分（例「輪舞-revolution」），没有时用文件名（例「OP」「絕對運命默示錄」）。
- 库里已有同名同版本：那一行「名称」后面写「（库里已有）」，「导入」一列变成下拉「替换」「另存为新的」「跳过」，默认跳过。
- 没认出来的行：底部「有 {n} 行没认出来，没有导入」，点开看每行「{文件} 第 {行号} 行：{原因}」。
- 按钮「导入」「取消」「帮助」。完成后状态栏：「已导入 {n} 首：{名称列表}。打开一集后用“集 → 查找并套用重复段落…”套用。」
- 「歌词文件」旁加按钮「粘贴歌词块…」：打开一个大文本框（标题「粘贴歌词块」），粘贴后按「读入」，和选文件一样进入上面的列表；
  文本框下方说明「写法见帮助；可以先用“复制提示词”让语言模型帮你整理」，按钮「复制提示词」「读入」「取消」「帮助」。
- 没有音频的段落：「查找并套用重复段落」左边列为「{类别}《{名称}》 没有音频，只能手动套用」（灰色）；选中后按钮「从当前组开始套用」：
  以列表里当前选中那一组的开始时间作为这一段的开始，生成同样的对照表（不缩放）。没有选中组时按钮灰掉「（先在列表里选中这首歌的第一组）」。
- 歌词块有错误时，在「没认出来的行」里列出：「歌词块 第 {n} 块：{原因}」，原因沿用 2.3 的对应错误和下面 4.4 的格式错误。

### 4.4 歌词块（新写法）
一句歌词一块，块与块之间空一行。每行「名称：内容」，冒号全角半角都可以；没有的行可以省略。以 `#` 开头的行是说明，忽略。

```
# 歌名：輪舞-revolution
# 类别：片头曲
时间：0:00:25.84 - 0:00:30.01
原文：光差す校庭 手をとり合い
读音：光（ひかり） 差す（さす） 校庭（ガーデン） 手（て） 合い（あい）
假名拍：{\kf16}ひ{\kf25}か{\kf22}り{\kf37}さ{\kf23}す{\kf37}ガー{\kf80}デン{\kf24}て{\kf22}を{\kf24}と{\kf23}り{\kf35}あ{\kf49}い
翻译：在陽光映照的校庭  握著彼此的雙手
对应：在（ひ）陽（か）光（り）映照的（さす）校（ガー）庭（デン）握（て）著（を）彼（と）此（り）的（あ）雙手（い）
```

- 「# 歌名：」「# 类别：」写在第一块前面，对后面所有块有效，直到出现新的「# 歌名：」（一个文件可以放几首歌）。类别写「片头曲」「片尾曲」「插曲」。
- 「时间」：这一句在集里的开始和结束（和 Aegisub 一样的写法）。「假名拍」里的 `{\kf数字}` 是从这一句开始算的百分之一秒；没有字的 `{\kf数字}` 是停顿。
- 「读音」：只写有汉字的词，「词（读音）」，送假名包含在词里（「合い（あい）」），读音用平假名；歌里的特殊读法照写（「校庭（ガーデン）」）。
- 「对应」：写法同 2.2。只有翻译（例如英文歌词）的句子可以只写「时间」「翻译」，翻译里可以带 `{\kf数字}`（英文按词或音节）。
- 格式错误：「第 {n} 块没有“时间”」「第 {n} 块的时间写法不对：{内容}」「第 {n} 块“读音”里的「{词}」在原文里找不到」「第 {n} 块“假名拍”的假名和原文的读音对不上」，以及 2.3 的对应错误。
- 以前的一行写法（「K轴」注释行 `{\kf…}…\N{KaraOKMapping:…}{CNOrigin:…,JPOrigin:…,KanaOrigin:…}`）照样认得，不用改。

### 4.5 让语言模型帮忙整理
帮助里给出下面这段提示词（导入窗口的「复制提示词」复制的就是它），用户把三份资料贴在后面，交给 Claude（例如 Sonnet）或其他语言模型，
得到的歌词块再粘贴回来。程序会逐块校验，模型写错的地方会列出来，不会悄悄导入。

```
请帮我把一首日语歌整理成“歌词块”。我会给你三份资料：
1. 日文歌词，每行一句；
2. 中文歌词，每行一句，和日文一一对应；
3. 用 Aegisub 打好的卡拉 OK 时间轴，只有假名，每行一句，是 ASS 字幕行（Dialogue 或 Comment 行，里面是 {\kf数字}假名）。

每一句输出一个歌词块，块与块之间空一行，格式：
时间：开始 - 结束        （照抄第 3 份资料里这一行的开始和结束时间）
原文：日文歌词
读音：词（读音） 词（读音）……   （只写有汉字的词，送假名写在词里，读音用平假名；特殊读法按假名时间轴里实际唱的写）
假名拍：{\kf数字}假名{\kf数字}假名……   （照抄第 3 份资料，不要改任何数字和假名）
翻译：中文歌词            （照抄，不要改字）
对应：中文一段（这一段唱的假名）中文一段（假名）……

“对应”的规则：
- 把中文按意思切成几段，每段后面的括号里写它对应的假名，必须是假名拍里连续的几拍，按顺序把这一句的假名全部用完；
- 所有括号里的假名连起来，要和这一句假名拍里的假名完全一样（停顿不算）；
- 中文不能改字、不能漏字；空格和标点跟在前一段后面；
- 尽量让意思对得上：日文唱到“光”的时候，中文也在唱“陽光”。
只有中文、没有日文的句子（例如英文歌词）只写“时间”和“翻译”。
不确定的地方在那一块最后加一行“备注：……”。只输出歌词块，不要别的说明。

第 1 份（日文歌词）：
……
第 2 份（中文歌词）：
……
第 3 份（假名时间轴）：
……
```
- 「备注：」行会显示在导入列表的提示里，不导入。
