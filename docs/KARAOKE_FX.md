# 多种卡拉 OK 特效（KARAOKE.md §5.1）— 设计

状态：Claude 2026-10-05 定（用户 2026-10-04：C、D、F 之后接卡拉 OK，同意阅读参考资料）。界面文字以本文件为准（「」里照抄）。
参考：karaokes.moe 进阶指南（演唱者配色、振假名对应、拆行保留拍）、kakashi1987 的 Aegisub/PyonFX 特效合集（约 80 个模板；**没有写许可证，只学思路，不复制模板或代码**）。

## 1. 思路（从参考资料学到的机制，用我们自己的方式实现）
- 一个特效 = 按拍（或按字）生成若干 ASS 行：**入场**（行开始前出现/飞入/淡入）→ **唱到**（这一拍放大、发光、跳、变色、擦除……）→ **退场**（唱完保持到行尾或逐字消失）。
- 用到的 ASS 手段：`\t` 变化（字号、边框、模糊、颜色）、`\move`、`\fad`、`\clip` 擦除、多层（光晕层在下、模糊）、`\p1` 小图形（星、心、圆、花瓣）做粒子。
- 我们已经有：每一拍的时间（K 轴）、每个字和每个振假名在画面上的实测位置（版面索引，libass 测量）。特效模块直接用这些，不需要 Lua 或 Aegisub。
- **预览和导出走同一条路**（看到的就是发布的）；带随机的特效用固定的种子（按行），每次导出结果一样。

## 2. 特效列表（第一批）
共同参数：「提前出现（毫秒）」默认 300、「唱完后保留（毫秒）」默认 0（到行尾）、「淡入/淡出（毫秒）」默认 150/150；
「振假名跟着」默认勾、「翻译行跟着」默认勾（翻译行按自己的拍）。颜色默认取模板里歌词的“唱到/未唱”颜色。

## 3. 双行卡拉 OK（KTV 样式）
- 一首歌的行两两交替显示：第一行在「左上」、第二行在「右下」（或「上下两行居中」）；唱第一行时第二行已经以“未唱”颜色等在那里，
  第一行唱完后它的位置换成第三行（提前出现），依此类推。翻译行跟着各自的原声行。
- 和上面的特效可以叠加（例：双行 + 渐变扫过）。
- 参数：「排列：左上 / 右下 · 上下两行居中」「换行提前（毫秒）」默认 600。

## 4. 用在哪里、怎么选
- K 工具栏的「特效」下拉列出所有特效；旁边「参数…」打开参数面板（滑块、颜色选择、开关），**改参数时画面上马上看到**（F10/F11 和预览）。
- 「应用到：这一行 / 选中的组 / 整首歌」——整首歌 = 同一首歌（同一个歌曲类别 OP/ED/IN 的歌曲组）的所有行。一次应用一步撤销。
  夹在歌词中间的其他组（例如片头的制作人员字幕）不打断一首歌：相邻两句歌词相隔不超过 15 秒就算同一首（实测巌窟王 E02 的 OP 被制作人员字幕分成了 5 段，2026-10-05 修正）。
  双行 KTV 的“一首歌”用同样的规则。
- 「存为预设…」：把特效和参数存成工程预设（`dict/karaoke_fx.json`），以后在下拉里直接选；重复段落库套用歌曲时连特效一起套。
- 列表右键「K 轴特效 ▸」列出全部注册的效果及工程预设，和工具栏同源；选中多句时只改歌曲组，整次一步撤销。
- 换特效不改拍（和现在一样）。
- 惊恐颤抖按原 ASS 的离散位置抖动思路独立实现；未唱透明度 0–255，默认 208，唱到恢复。跟随振假名按实际排版的本字身份关联，熟字訓／多汉字的一块注音与所有本字同轨；整行模式则全行共用位移。长句先加大移动间隔（最多 200 毫秒）并在报告提示，仍无法满足上限才走原降级规则。

## 5. 导出
- 选了特效的行导出成生成的多条 ASS 行（原来那一行不再单独出现）；报告写「卡拉 OK 特效：{n} 行生成了 {m} 条字幕行」。
- 每行最多生成 2000 条，超过时这一行退回「渐变扫过」并在报告里写明「{时间} 这一行特效太复杂，已改用渐变扫过」。
- 不认识的特效名：导出报错「未知的卡拉 OK 特效：{名字}」，不会把名字留在发布文件里。
- 振假名、翻译行按“跟着”选项生成；占位拍、起音建议和没打完的行也按所选特效显示和导出，仍在待办里列出。歌曲行没有 K 轴时使用平均分配的占位拍；勾选“翻译行跟着”时，没有自己的 K 轴的翻译行也按自己的占位拍使用原声特效。

## 6. 验收
- 每个特效：libass 渲染的截图（唱到前 / 唱到时 / 唱完）在预期位置变化；预览和导出逐字节相同；同一行两次导出结果相同（随机种子固定）。
- 少女革命 OP 的一段（测试工程副本）套用「发光」「星光」「双行」导出能在 mpv 播放；现有 kf 导出逐字节不变。
