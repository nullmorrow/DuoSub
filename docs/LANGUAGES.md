# C 语言不写死 + 拼音（PLAN-1b C）— 设计

状态：Claude 2026-10-04 定（用户：C、D、F 依次做，没有问题就一直做）。界面文字以本文件为准（「」里照抄）。

## 1. 原则

- 双语字幕 = 原声 + 翻译，两边可以是任何语言；**注音按语言决定**：日文 → 振假名；中文（zh-Hans / zh-Hant）→ 拼音（工程选项，默认关）；其他语言 → 没有注音。
  中文可能在翻译一边（常见），也可能在原声一边（华语片配日文翻译），规则跟着语言走，不跟着“原声/翻译”走。
- 现有日文 + 中文工程的行为**完全不变**（默认拼音关；日文规则照旧）。

## 2. 拼音

### 2.1 数据
- 注音 `kind: "pinyin"`，挂在每个汉字上（一个字一个注音），`text` 存带声调的拼音（`háng`、轻声 `le`）；显示方式在导出时转换：
  拼音 PY（声调符号）/ 注音 ZY（ㄏㄤˊ）/ 威妥玛 WG。`candidates` 存多音字的候选。
- 状态和振假名一样：自动 / 你确认过 / 不标注；人工改过的不会被刷新覆盖。多音字不标“待确认”（太多，干扰），只在候选里列出。
- 工程设置 `settings.pinyin = {"mode": "off" | "PY" | "ZY" | "WG"}`，默认 `off`。

### 2.2 生成
- 用本机已装的 pypinyin，按整句上下文选读音（基线 `subkit/pinyin.py` 的 `line_pinyin`：只把汉字送进去再对回位置）。
- 打开拼音时给所有中文行生成自动拼音；改字后像振假名一样只刷新改动的行；关掉拼音时**不删数据**，只是不显示、不导出（再打开时你改过的还在）。

### 2.3 编辑（和读音一样的手感）
- 观剧模式右键中文字、编辑区拼音行上点字 → 拼音弹窗：候选（数字键选）、直接输入。
  输入方式：「hang2」「háng」都可以（数字 1–4 是声调，5 或不写是轻声；v 代表 ü，例如「lv4」→ lǜ）。
- 范围：只改这里 / 这一集都这样 / 整个工程都这样（和读音同一套，规则存“拼音规则”，按词：例如「行长 → háng zhǎng」）。
- 弹窗标题「拼音：{字}」；按钮「不标注」「确定」「取消」；范围选项文字同读音弹窗。
- 输入不对时：「拼音无效：请输入有效的拼音音节（如 hang2、háng、lv4；5 或不写数字为轻声）。」
  词规则的音节数和字数对不上：「拼音规则须为每个汉字填写一个音节，用空格分隔。」

### 2.4 导出与显示
- 拼音行画在中文上方，和振假名同一个排版器（逐字对齐、过挤时压缩），样式用模板的「{中文样式}.Pinyin」（模板编辑器里已有拼音字号和位置）。
- 观剧模式、预览和导出一致；审议包里中文写成 `行(háng)长(zhǎng)`（只写多音字和你确认过的，避免整句都是括号）。

### 2.5 菜单
- 文件菜单：「拼音设置…」→ 对话框「拼音」：「显示拼音：关 / 拼音（声调符号）/ 注音符号 / 威妥玛」，说明「只影响中文行；关掉时你改过的拼音会保留」。
  打开时如果这一集还没有拼音，自动生成（有等待光标）。

## 2.6 一键简体转繁体（用户 2026-10-05）
- 视图菜单「简体中文显示为繁体（只影响预览和导出，原文不变）」（勾选项，按工程记住），旁边子菜单「繁体用字：台湾（默认）/ 香港 / 标准繁体」，
  勾选框「同时转换用语（例：软件→軟體）」默认不勾。用本机的 OpenCC（`s2tw` / `s2hk` / `s2t`，用语转换用 `s2twp`）。
- **只转语言是简中（zh-Hans）的行**（按每一行的语言，不按原声/翻译）；日语行一个字都不碰（日文汉字不会被当成简体转换）。
- 和「隐藏日文句末「。」」一样是**显示规则**：工程里的文字、读音、拼音、K 轴都不变（拼音按字挂着，繁简同音），关掉就回到原样；
  观剧模式、预览、导出、审议包用转换后的文字；编辑区和就地编辑框里显示工程里的原文，旁边小字「导出为繁体」。
- 名字栏：人物有繁中名字就用繁中名字，没有就把简中名字按同样的方式转换。
- 导出报告写「简体转繁体：{n} 行（台湾用字）」。

## 3. 语言不写死

### 3.1 原字幕分析（导入时）
- 日文：照旧（ja-cc）。
- 英文（en）：新的分析器 en-sdh：行首的说话人 `JOHN:` / `[John]` / `(JOHN)`；效果音 `[door creaks]` `(laughs)`；`♪` 歌词/音乐；对话破折号 `- `；
  都是结构化元数据（不删字，台账照常平衡）；不确定的不标。
- 中文和其他语言：只处理 SRT 格式标签和对话破折号（和现在的通用部分一样），不猜说话人。
- 已导入的集不受影响；「重新分析原声字幕」按这一集原声的语言选分析器。

### 3.2 分句（移动分界、拆分用的“短语”）
- 日文：照旧（空格、句末标点）。中文：，。！？；、和空格。英文等用空格分词的语言：句末标点 . ! ? 和逗号、分号；**不在单词之间的空格切**。

### 3.3 语气词
- 按语言的语气词表：日文照旧；中文：啊 嗯 哦 呃 欸 唉 哎 哈 呀 喔 噢 嘿；英文：uh um oh ah hmm huh er eh mm（大小写、重复字母、标点不影响判断）。
- “简洁模式”只对有语气词表的语言生效。

### 3.4 界面文字
- 界面里写死的「日文」「中文」改成按工程语言显示：原声一边「原声（日语）」、翻译一边「翻译（繁中）」；只说语言时用「日语 / 英语 / 简中 / 繁中 / {语言代码}」。
  语言名：ja 日语、en 英语、zh-Hans 简中、zh-Hant 繁中、ko 韩语、fr 法语、de 德语、es 西班牙语，其他显示语言代码。
- 只对日文有意义的功能（振假名、隐藏句末「。」、K 轴的假名拍）在原声不是日文时隐藏或灰显，并说明「只对日文有效」。
- 删除菜单「只删日文 / 只删中文」改为「只删原声 / 只删翻译」。

## 3.5 面向公开发布：每种语言一张数据表（用户 2026-10-04：最终要公开发布，会有韩语原声、汉语原声 + 越南语翻译等）
- 和语言有关的规则全部来自一张“语言数据表”（每种语言一条），代码里不再写死某种语言；加一种语言 = 加一条数据。每条包括：
  显示名（界面用）、文字是否用空格分词、分句标点、语气词表、原字幕分析器（ja-cc / en-sdh / 通用）、注音方式（振假名 / 拼音 / 无，以后可加粤拼、韩文罗马字等）、
  人名默认顺序（姓在前 / 名在前）和姓名连接符、可选的人名识别方式（见 CHARACTERS 5b）。
- 范围（用户 2026-10-04）：**中日韩 + 用字母拼写的语言**（英、越、法、德、西、葡、意、俄……）；从右往左的文字（阿拉伯语、希伯来语）和泰语这类特别复杂的不考虑。
- 第一批：日语 ja、简中 zh-Hans、繁中 zh-Hant、粤语 yue（暂按繁中、无注音）、韩语 ko、英语 en、越南语 vi、法语 fr、德语 de、西班牙语 es、葡萄牙语 pt、意大利语 it、俄语 ru。
  例：韩语 姓在前、韩文名不加连接符（김민수），无注音；越南语 姓在前、空格（Nguyễn Văn An），按空格分词。
- 表里没有的语言：按文字自动判断是否用空格分词，名在前、空格，通用分析器，无注音、无语气词——能用，只是少了专门的规则。
- 现有日语 + 中文工程的行为和导出不变。

## 4. 不做（这次）
- 粤拼、韩文罗马字、英文旁注（gloss）——数据结构已允许，以后按需要加。
- 自动判断字幕语言：语言仍由添加一集时选择。

## 5. 验收
- 现有全部测试不变通过；日文 + 中文工程的导出逐字节不变（拼音关时）。
- 拼音：E01（食戟测试工程）开拼音后导出的拼音行位置与模板预览一致（libass 实测）；多音字「行」「长」「了」按上下文；改一个字的拼音保存重开不变；关掉再开不丢。
- 英文：用一份带 `JOHN:` `[laughs]` `♪` 的英文 SRT 合成样本导入，说话人、效果音、音乐都成为元数据，台账缺失 0、重复 0；短语不在单词间切。
