# 程序内帮助（设计，Claude 2026-10-04）

使用说明只有一份：`docs/manual/index.html`（用户找功能用，一直更新）。程序里的帮助都打开它的对应章节，不另写一套。

## 1. 帮助菜单（文字照抄）

- 「使用说明」 `F1` — 打开说明，跳到当前操作对应的章节（见第 2 节）。
- 「快捷键一览」 — 打开说明的「快捷键一览」一节（`#keys`）。原来写死在程序里的快捷键提示框去掉（内容已经过时，说明里有完整的一份）。
- 「版本记录」 — 打开 `#changes`。
- 「关于双语字幕工坊」 — 小对话框：「双语字幕工坊（DuoSub）{版本}」「原名 SubKit。原生双语字幕编辑器：配对、调轴、读音、K 轴。」「使用说明：{说明文件路径}」，按钮「打开使用说明」「关闭」。

找不到说明文件时：「找不到使用说明：{路径}」。

## 2. F1 对应的章节

在任何窗口（包括对话框、读音弹窗、就地编辑框）按 `F1`，按当前情况打开：

| 当前情况 | 章节 |
|---|---|
| 自由变换中 | `#transform` |
| 观剧模式（F10/F11） | `#watch`；选中的是歌曲组时 `#karaoke` |
| 读音弹窗（含按单个汉字拆开） | `#readings` |
| 设置开始和结束时间 | `#timing` |
| 列表右键复制这一组 / 复制这 n 组 | `#review` |
| 样式模板对话框 | `#template` |
| 标点和空格（含半宽假名／长音标准化）及标点方案 | `#display-rules` |
| 添加一集 / 合并对话框 | `#add-episode` |
| 转为歌曲 / 转为普通台词 | `#karaoke` |
| 列表右键全部 K 轴特效（含惊恐颤抖）、特效参数面板 | `#karaoke-fx` |
| 记为重复段落 / 重复段落库 / 查找并套用重复段落 | `#passages` |
| 导出（含整季同时导出审议包）、字体检查的提示和报告 | `#export`（字体相关 `#fonts`） |
| 焦点在波形 | `#timing`；当前是歌曲组时 `#karaoke` |
| 焦点在格式栏 / 位置栏 | `#format` / `#position` |
| 焦点在组列表、组编辑区、原文面板 | `#review` |
| 其他 | 说明开头 |

有“帮助”按钮的对话框（上面列出的对话框都加一个「帮助」按钮），点按钮和按 F1 一样。

## 3. 菜单提示

每个菜单项都有状态栏提示（一句话说明做什么），菜单项的说明和使用说明里的名字一致。

## 4. 保持一致（自动测试）

- 程序里用到的每个章节锚点都存在于说明里。
- 每个菜单项的名字（去掉 `…`、`(&X)` 和括号里的补充）都能在说明里找到；新加菜单项没写说明，测试就失败。
- 说明里写的版本号等于程序的版本号。
