# K 轴（卡拉 OK）设计（Opus，2026-10-02）

任务书第十四节、验收 14。目标：**不再需要 Aegisub**，在 SubKit 里边看边打 K 轴，打一次、后面每集复用。

## 0. 现状和用户成品里的做法

- 旧工具：每个歌曲行有一条 `@K` 注释行（假名 + `\k`），**要在 Aegisub 的卡拉 OK 模式里打**；没打时写平均分配的占位并留 ⚙ 提示；
  中文用 `@K中` 文字记法映射（`緊抱我（で） 世界（せかい）`）；特效写 `{@fx:名字}` 槽。SubKit-Opus 目前完全没有 K 轴。
- 用户的少女革命成品（E01 OP/ED，202 行带 `\kf`）：
  - 日文行：假名逐拍 `\kf`；汉字块拿到它所有拍的总时长（`{\kf71}潔` = い21+さ14+ぎ19+よ17）；
  - 振假名：每个汉字块一条，先一个空拍等到开始，再逐拍：`{\kf199}{\kf24}い`、`{\kf16}ひ{\kf25}か{\kf22}り`；
  - 唱法和词典读音不同就改读音：`校庭` 唱成 `ガー|デン`；
  - 中文行逐字 `\kf`，按日文的片段对齐（`臉頰|比鄰相貼|所拍下的|照片`），英文按词（`{\kf18}Just {\kf5}a {\kf33}long`）；
  - 休止是空拍（行首 `{\kf14}`、行中 `{\kf24}`）；`っ` `ー` `ン` 大多跟前一拍（`なっ` `ガー` `ホン`），个别地方单独一拍（`メ|ッ|キ`）。

**原则：沿用旧版。** 对应关系（假名拍 → 汉字块 / 假名 / 振假名 / 中文片段）、`\kf` 的写法（汉字块拿总时长、振假名先空拍再逐拍、
中文逐字按片段映射、英文按词、休止是空拍）都和旧版、和少女革命成品一致；旧版的映射算法（假名流对齐、`@K中` 片段映射、
振假名逐拍）直接复用；旧工程里的 `@K` / `@K中` 记录可以导入。变化只有两点：拍在 SubKit 里打（不用 Aegisub），
数据挂在字上（改字、改读音、移动短语时跟着走）。

## 1. 概念

| 词 | 意思 |
|---|---|
| 拍 | K 轴的最小单位：一段被唱的文字 + 开始/结束时间（绝对时间，毫秒）。 |
| 原声拍 | 原声歌词（例如日文）的拍。每拍对应底字的一段，汉字块的拍还对应读音的一段（`心`=こ\|こ\|ろ 三拍，底字都是 `心`）。 |
| 翻译拍 | 翻译歌词（例如中文）的拍：默认一字一拍，英文一词一拍。边界可以**吸附**到原声拍的边界上，原声改了它跟着动。 |
| 休止 | 两拍之间没有唱的时间。导出成空拍。 |
| 状态 | 占位（平均分配）／建议（音频起音给的）／已打（用户打拍、拖过或套用歌曲记忆）／已确认。占位和建议**不算完成**，发布检查会列出。 |
| 特效 | 和拍分开存：`kf`（默认，用户成品用的）、`k`、`ko`、`none`，以及可扩展的特效模块。换特效不动拍。 |

## 2. 怎么打（用户操作）

### 2.1 分拍——自动，不用手写
选中一个歌曲 Group，拍就已经按文字和读音分好了：
- 汉字块按读音分拍（振假名就是我们已有的读音，`潔`→い\|さ\|ぎ\|よ）；假名一字一拍；
- 默认“音节”粒度：小写假名、`っ`、`ー`、`ん` 跟前一拍（`なっ`、`ガー`、`ホン`）；工程设置可改成“拍（mora）”粒度；
- 英文一词一拍；数字/字母词整体注音的按读音分拍；标点和空格跟着前一拍（行首的跟后一拍），不单独占拍；
- 唱法不同就改读音（右键汉字 → 输入 `ガーデン`），拍自动重分。
- 手动调整：K 轴条上 **Ctrl+点两个字之间 = 拆开**，**Ctrl+点拍的边界 = 合并**（和 Aegisub 的卡拉 OK 拆分一样直观）。拆合是数据，不会被重算覆盖。

### 2.2 边听边打——按住 K 跟唱
- 选中歌曲行，按 **K**：从行首前 0.5 秒开始播放；**按下 K = 这一拍开始，松开 = 这一拍结束**（像跟着唱）。
  松开到下一次按下之间如果不到 150 毫秒（可调），算连唱，不留休止；更长就是休止。
- 正在等的那一拍在 K 轴条上高亮；最后一拍松开后停在本行，波形上显示刚打的拍，可以马上修。Esc 放弃（不改任何东西），Ctrl+Z 撤销。
- **刷剧连打**：观剧模式里歌曲正常播放时直接按住 K 跟唱：按下落在哪一行的时间里，就依次给那一行的下一拍；
  一首歌唱一遍就有了第一版 K 轴，行数对不上的地方会标出来。
- **从这一拍重打**：点 K 轴条上的某一拍再按 K，从这一拍往后重打，前面的拍不动。
- 慢速：0.5× / 0.75× / 1×（音高不变），快歌放慢了打，时间按原速记录。
- 打拍提前量：全局设置（默认 0），也可以打完整行一起平移（`,` `.` 每次 10 毫秒）。

### 2.3 波形上修——和 Aegisub 卡拉 OK 模式一样
- 歌曲行的波形显示每一拍的边界和文字（汉字块的拍显示读音，例如 `心` 上面是 こ\|こ\|ろ），下面一条是翻译拍。
- 拖边界 = 相邻两拍一个变长一个变短；Shift+拖 = 后面的拍整体跟着移；点一拍 = 播放这一拍；双击 = 从这一拍播到行尾。
- 波形可切换成**频谱**（唱歌的起音在频谱上比波形清楚得多）；可开“吸附到起音”（默认关）。
- 左键/右键单击空白处仍然是行的开始/结束（Aegisub 习惯），不影响拍。

### 2.4 翻译歌词怎么对上
- 默认建议：两边都按空格/标点分成同样多的片段时，片段对片段，片段内平均分；否则整行按字数平均分。状态是“占位”。
- 改：拖翻译拍的边界，靠近原声拍边界时会吸附（按住 Alt 不吸附）；吸附的边界以后跟着原声拍走，没吸附的按比例插值。
- 也可以直接打翻译拍：按 Tab 把打拍对象切到翻译行，再按 K。

### 2.5 自动建议（只建议，不算完成）
- 平均分配：明确标“占位”。
- 起音建议：从音频算起音强度（频谱通量，numpy，本机即可，不需要模型），在行的时间范围内找最合理的拍点；显示成虚线，按 Enter 采用或直接拖改。
- 不启动、不下载任何模型。人声分离模型能明显提高建议质量，但要下载，只有你同意后才会考虑。

### 2.6 歌曲记忆——打一次，每集复用（已完成，0.5.0；属于“重复段落库”，PLAN-1b E）
- 一首歌某个版本的 K 轴确认后，用“记为重复段落”存入工程的 `dict/passages.json` 和音频模板 `dict/passages/<ID>.npz`；`dict/songs.json` 不再使用。记录歌词行、确认的读音、拍、翻译吸附、特效与来源集数，占位拍不记录。
- 新的一集音频读完后自动查找，在状态栏提示；用“查找并套用重复段落”试听并逐项确认。读音和 K 轴只套到文字完全相同的行，人工成果冲突默认不勾选，一次应用一步撤销。界面文字与完整规则见 `PASSAGES.md`。
- 整段平移直接保留轴；如果行的时长对不上（版本不同、剪辑不同），**只标出差异**，按比例缩放必须你选择，并先预览前后对比。
  相同歌词 ≠ 同一版本：版本由你命名（TV / 完整版 / 插曲……），匹配依据始终显示。

### 2.7 普通台词和歌曲互相转换（用户追加 2026-10-03，已完成 0.4.2）
- 问题：只有导入时就被认成歌曲的组才能打 K 轴；被当成普通台词导入的插曲、歌词没法转过来。歌曲也要能转回普通台词。
- **转为歌曲（K 轴）**：在列表里选一组或多组 → 右键（或 编辑 菜单）→ “转为歌曲（K 轴）…” → 选 片头曲 OP / 片尾曲 ED / 插曲 IN
  → 组变成歌曲，样式换成 `OP.CN` / `OP.JP`（按合并时的样式命名）。之后选中按 K 就能打轴；原字幕里自带 `\k` 的可以照常“读入原字幕的 K 轴”。
- **转为普通台词**：右键 → “转为普通台词…”，确认后：样式和角色恢复成转换前的（没有记录的用 `CN` / `JP`）；
  已打的 K 轴**保留在工程里但不导出**（转回歌曲时原样恢复，不用重打）；原字幕里自带的 `\k` 不写进输出（原字幕不变，导出报告写明）。
- 转换只改组的种类、成员的角色和样式；文字、时间、读音、位置都不动。同一句歌词的光晕层（同时间、同文字的另一图层）一起转换并在确认框里列出。
  一次转换一步撤销。

## 3. 联动规则

| 操作 | K 轴怎么变 |
|---|---|
| 平移整个 Group（拖条中间、整体偏移） | 原声拍、翻译拍、振假名拍一起平移。 |
| 改行的开始/结束（左键/右键） | 拍不动（唱的时间没变）。拍落到行外会标出来；“把拍按新时长缩放”是单独的明确操作。 |
| 改读音 | 这个汉字块的拍重分；拍数没变就保留时间，变了就在原时间段里平均分并标“读音改了，需重打”。 |
| 改字、移动短语、合并、拆分 | 拍挂在字符身份上，跟着字走；被删的字的拍去掉；新字是占位拍并标出。 |
| 换特效 | 拍不动。 |
| 用歌曲记忆 | 只平移；缩放要确认。 |

## 4. 数据（FORMAT-v1 §6.7 r2，已实现）

只存每一拍的时间，键是“这一拍自己的字（字符身份）+ 块里第几拍 + 唱的假名”；拍的结构每次从当前文字和读音推出。
这样改字、改读音、移动短语都不会留下错位的旧轴：字和读音没变的拍时间不变，改过的地方变成占位并标出来。
时间是绝对时间（毫秒），改行的开始不影响唱的时间，平移 Group 时一起平移。详见 FORMAT-v1.md §6.7。

## 5. 导出

- 原声行：每拍前插 `\kf`（或特效选的 `\k` `\ko`）；汉字块一个标签；行首/行中休止 = 空拍；标点、空格跟前一拍。
- 振假名行：每个汉字块一条（现在的排版），`{\kf<等待>}` 后逐拍；拼音同理（中文开拼音时）。
- 翻译行：逐拍。
- 扩展特效：特效模块拿到拍、每个字的实测位置、振假名的位置和参数，生成真正的 ASS 行；预览和导出走同一条路，所见即所得。
  不认识的特效 → 导出报错，不会把槽名留在发布文件里。
- 发布检查：占位/建议的拍、拍在行外、拍数和读音对不上 → 列出；可以选择仍然导出，报告里写明。

### 5.1 卡拉 OK 特效库（用户追加 2026-10-03，计划中）
- 现在只有 `kf`（渐变扫过）/ `k`（瞬间变色）/ `ko`（描边先出现）/ `none`。要加多种效果，像 Aegisub 卡拉 OK 模板（kara-templater）做的那样。
  每个效果是一个“逐拍生成 ASS 行”的模板，参数可调，预览和导出走同一条路；振假名、翻译行跟着同一个效果。计划中的效果：
  - 放大弹出：唱到的拍放大再回落（`\t(\fscx\fscy)`）；
  - 发光：唱到的拍边框变色、加模糊光晕（`\t(\3c\blur)`，配合光晕层）；
  - 跳动：唱到的拍向上跳一下（逐拍拆行 + `\move`）；
  - 变色/彩虹渐变（`\t(\1c)`）；逐字淡入、唱完淡出（`\fad` / `\t(\alpha)`）；
  - 旋转/抖动（`\frz`）；擦除（`\clip` 扫过，横向/竖向）；
  - 粒子/星光：唱到的拍周围飘出小图形（`\p1` 绘图 + `\move` + `\fad`）；
  - 入场/退场：逐字从下方飞入、唱完散开。
  - **双行卡拉 OK**（两行歌词交替显示：一行唱完换下一行，另一行提前出现等待）；
  - **字体变形**（唱到的字形变：拉伸、扭曲、缩放波动等）。
- **TO-DO，暂不研究**：等用户明确说可以去看（有额度）时，再读下面的参考资料、整理效果清单和参数：
  - https://docs.karaokes.moe/contrib-guide/create-karaoke/karaoke-advanced/index.html
  - https://github.com/kakashi1987/aegisub-lua-pyonfx-karaoke-fx-collection （Aegisub Lua / PyonFX 特效合集）
  - 用户最早给的 huyhuu.com 页面只有特效包的下载链接，没有说明；SubKit 不从这类来源下载文件。
