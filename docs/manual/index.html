双语字幕工坊 使用说明

双语字幕 = 原声（例如日文 CC）+ 翻译（例如中文）。这个程序把两份字幕合并成一个可以一边看片一边配对、调轴、改读音、打 K 轴的工程，最后导出发布用的 ASS。 左边目录可以搜索；在程序里按 F1 会直接打开当前操作对应的这一节。

快速开始

  1. 启动：双击项目文件夹里的 DuoSub.lnk（带 DuoSub 图标的快捷方式，可以复制到桌面或固定到「开始」）或 DuoSub.pyw（用本机的 Python 3.12，不需要命令行；.pyw 文件本身只能显示 Python 的图标）。窗口左上角和任务栏显示 DuoSub 图标。快捷方式丢了或换了电脑时，运行 tools\make_shortcut.ps1 重新生成。
  2. 新建工程：文件 → 新建工程…（Ctrl+Shift+N）。工程文件夹由你选，和程序、视频分开放。新建时就可以调好样式模板（字体、颜色、位置），右边是真实渲染的样子。
  3. 添加一集：集 → 添加一集…：选视频、翻译字幕、原声字幕，确认翻译字幕里每个样式（Style）的用途。
  4. 合并：集 → 合并（生成工作文档）…。程序按顺序把中日文配对成一组一组（不会交换顺序，不会删字）。
  5. 看片审核：按 F10 进入“看片打轴”（视频 + 波形），边看边点字幕修改；或者在编辑模式里用列表逐组处理。
  6. 导出：文件 → 导出 → 发布用 ASS…。导出前会检查顺序、原文去向、没打完的 K 轴和字体。整季一次导出用 文件 → 导出 → 整季发布用 ASS…（导出整季）。
所有修改都能撤销（Ctrl+Z / Ctrl+Y），每次操作一步。原来的字幕文件从来不会被改动。Ctrl+S 保存；程序每 30 秒另存一份恢复用的自动保存，异常退出后下次打开提示恢复。

打开工程后可以直接切换集或关闭程序；后台字幕位置预热会自动停止。

在程序里找帮助

  • F1（帮助 → 使用说明）：在任何窗口里按，都会打开这份说明里当前操作对应的一节（观剧模式、读音弹窗、K 轴、各个对话框……）。
  • 对话框里的「帮助」按钮：同上。菜单项的用途显示在窗口底部的状态栏。
  • 帮助 → 快捷键一览、帮助 → 版本记录、帮助 → 关于双语字幕工坊（版本号和说明文件的位置）。

对话框底部按钮从左到右是辅助操作、主操作、取消或关闭、帮助；辅助操作与右侧按钮之间留空。帮助始终在同一行最右侧，只打开对应说明，不关闭窗口。通常 Enter 执行默认操作，Esc 取消或关闭；删除、移除不会成为默认操作。读音弹窗的数字选候选、Alt+←／→ 和 Enter，以及批量替换表格内的 Enter 编辑规则保持原样；进度窗口用取消停止任务。

基本概念

  • 工程：一部作品一个工程。读音词库、人物、样式模板、重复段落库都按工程隔离，别的作品的读音不会串进来。
  • 集：工程里的一集。工具栏的“集”下拉框切换。
  • 组（Group）：编辑的基本单位——同一时刻要一起显示的翻译行和原声行。只有一种语言的组也可以存在（未配对），不会硬塞给邻句。
  • 原声 / 翻译：双语字幕的两边。界面标签按工程语言显示，例如「原声（日语）」「翻译（繁中）」；其他语言显示相应名称或语言代码。注音按成员语言决定：日语用振假名，中文可开启拼音。工程两边都没有日语时，振假名入口隐藏，隐藏日文句末「。」、括号片假名还原和 K 轴假名分拍灰显，说明「只对日文有效」。
  • 来源只读：工程里保存原字幕的一份字节完全相同的只读副本。每个字都记得自己来自哪一行，所以读音、K 轴挂在具体的字上，字移到哪里它们跟到哪里。
  • 原文去向（台账）：原字幕里每个字都必须有去向——在正文里、在同组备注里（被隐藏的语气词）、是说话人标签等元数据、或者被你删除。保存和导出前都会检查，不会悄悄丢字。
  • 人工成果优先：你确认过的读音、删除、隐藏、手打的 K 轴、设的位置，任何自动刷新都不会覆盖。

只开一个双语字幕工坊

两个窗口同时改同一个工程时，后保存的覆盖先保存的（文档、自动保存、工程设置都是），另一个窗口的改动会丢。

已经开着时再启动，不开第二个窗口；已有窗口最小化时还原并调到最前面，第二个进程以退出码 0 退出。启动带工程文件夹、已有窗口没有工程时，在已有窗口打开它；已有工程时只调到前面，状态栏提示「双语字幕工坊已经开着：只能开一个，避免两份同时改同一个工程」。每个 Windows 用户各一份，崩溃后的残留不挡住新启动；--smoke-test 不受限制。

工程与集

启动程序会打开上次的工程；打开工程会回到上次编辑的那一集，并恢复该集上次保存、切集或关闭时选中的字幕组和视频时间。列表将该组居中显示，波形和编辑区同步选中，视频加载完成后跳到记住的时间并保持暂停，不会自动播放。切换集时，各集分别记住自己的位置；编辑布局沿用已有设置。

原字幕组已删除时，选开始时间最接近记住时间的组；上次的集已不存在时打开第一集。没有位置记录时沿用默认选组。若有自动保存恢复提示，先处理恢复或丢弃，再恢复位置；恢复位置本身不会修改文档或增加撤销步骤。

保存与自动保存

正式保存：Ctrl+S 或「文件 → 保存」把当前集的改动写入正式文档。窗口标题包含工程名和当前集，有未保存的改动时末尾显示「●」。状态栏右侧常驻「已保存 HH:MM」或「有未保存的改动（上次保存 HH:MM）」；从没保存过的新集显示「还没保存过」。时间取本次正式保存，否则取正式文档的修改时间。

恢复用副本：每 30 秒把有改动的文档写入 journal/autosave.json，只在程序意外退出时用，不改正式文档，也不代表已经正式保存。本次写过副本后，保存状态的悬停提示为「恢复用副本 HH:MM（程序意外退出时用，不是正式保存）」。

关闭时询问：关闭程序、切换到别的集、关闭或换工程时，有改动会询问「这一集（集号）有未保存的改动。保存吗？」。「保存」（默认）先正式保存再继续；「不保存」丢掉上次保存之后的改动，正式文件不动，并删除恢复用副本，下次打开不再提示恢复；「取消」或 Esc 留在原处。询问框的帮助与 F1 打开本节。

「文件 → 关闭或换集时询问是否保存」默认勾选（推荐），记在本机；不勾选会恢复以前的做法，有改动时不问、直接正式保存。此菜单项没有独立快捷键，F1 打开本节。

只能开一个双语字幕工坊：两个窗口同时改同一个工程时，后保存的文档、自动保存和工程设置会覆盖另一窗口的改动。再启动会把已有窗口调到最前面，详见工程说明。

Ctrl+S 保存当前文档；程序每 30 秒另存一份恢复用的自动保存。异常退出后，下次打开这一集，若 journal/autosave.json 比已保存文档新且内容不同，会提示「上次没有正常关闭。找到 {时间} 的自动保存，比已保存的文档新。恢复它吗？」。

点「恢复」载入自动保存并标记为未保存，确认后按 Ctrl+S 保存；点「丢弃」继续使用已保存文档，自动保存改名为 autosave-discarded-{时间}.json（同名时另加编号），不删除文件。提示框的帮助和 F1 打开本节。

集 → 从工程中移除这一集…：确认框显示「把 {集} 从工程里移除？这一集的工作文件会移到工程文件夹里的「已移除」文件夹，需要时可以手动找回；原视频和原字幕不受影响。」点「移除」后，工作文件夹移到工程内的 已移除/{集}-年月日-时分秒（同名时另加编号），从集列表消失，切到下一集；最后一集则切到前一集，没有集时清空。原视频、原字幕与其他集保留。点「取消」不改动；不能用 Ctrl+Z 撤销，需要时可手动找回工作文件。后台添加／合并期间不能移除，菜单和确认框的 F1 打开本节。

原字幕副本

添加一集时，两份原字幕（原声、翻译）原样拷进这一集的 sources 文件夹（只读，记下 SHA-256）。之后读字幕、合并、导出都只用这份副本，不再读导入时的位置，所以原字幕可以挪走、改名或删掉，不影响工程；打开这一集也不再提示「原始文件已移动」。

副本找不到或内容被改过时，打开这一集会提示「这一集工程里保存的原字幕副本有问题」，列出哪一份、是「找不到副本」还是「副本内容和导入时不同」。仍可编辑；导出会缺原字幕里的样式和特效行等。点「修复…」，或随时用 集 → 原字幕副本（检查和修复）…（检查整个工程）：

  • 「从导入时的位置恢复」：导入时的文件还在、内容没变时直接放回。
  • 「在文件夹里查找…」：选一个文件夹（含子文件夹），按内容找和导入时一字节不差的文件，文件名改过也能找到。
  • 「选择文件…」：给表格里选中的一行指定文件。

只接受和导入时完全相同的文件（SHA-256 一致），内容不同时提示「这个文件的内容和导入时不同（SHA-256 不一致），不能当作原字幕副本」，不会拿别的版本顶替。内容被改过的旧副本改名为 …changed-年月日-时分秒 留在原处，不删除。窗口的帮助和 F1 打开本节。

视频文件位置

工程只记住视频在哪里。视频挪过位置或改过名字时，打开那一集会提示「找不到这一集的视频」（字幕不受影响，只是没有画面和波形），点「重新指定…」打开 集 → 视频文件位置…（也可随时打开）：

  • 表格列出每一集记录的视频和状态（找得到／找不到／没有视频）。
  • 「在文件夹里查找…」：选一个文件夹（含子文件夹），给找不到视频的集自动配对，依次按「同名」「文件大小相同」（挪动或改名后大小不变）「集号」（文件名里的 E05、- 05、[05]、第05話 等）；一个文件只配一集，拿不准的不配。
  • 「选择文件…」：给选中的这一集选视频；同一个文件夹里其他找不到视频的集会一起配对。
  • 「应用」后才写入，状态栏显示「已重新指定 n 集的视频」；正在打开的这一集马上换成新视频。音轨选择保留。

波形和精确对话轴、自动 K 轴的缓存按视频的大小和修改时间记，不按路径，挪动视频后不用重新计算；以前版本按路径记的缓存在第一次使用或重新指定时自动改名沿用（以前做过、挪动前没再打开过的歌曲 K 轴缓存可能需要重算一次）。窗口的帮助和 F1 打开本节。

样式模板

「从 .ass 文件读取…」可以采用字幕组的对白外观：先新建工程、选好模板，再导入整季。DuoSub 的 CN / JP 模板仍直接读入（含歌词等样式，并保留其他样式）。其他 ASS 文件打开「从 .ass 读入样式」，分别选择用作翻译和原声的样式；列表显示行数和例句，自动推荐主要对白，定位特效不自动选中。同名样式采用文件中的最后定义，一侧选「（不读入）」就保留那一侧。

默认勾选「字体和字号」「颜色和边框」，「距底边」默认不勾选：DuoSub 会按振假名自动排开中日两行，一般不用读。字体选项也读入粗体、字距和边框宽度；颜色选项读入文字、边框及阴影颜色和支持的透明度。字号、边框宽度和距底边按源文件 PlayResY 换算到模板高度 1080，缺少 PlayResY 时按 1080 处理。只修改勾选的部分，保留顶部、第二人、歌词比例、注音与上下微调等设置，字幕组的其他样式不会加入模板。点「读入」刷新预览并显示来源、样式与读入部分；「取消」或 Esc 保留原值。「帮助」与 F1 打开本节。

每集字幕坐标跟随视频显示宽高比（含像素宽高比）：默认高 1080，4:3 为 1440×1080，16:9 为 1920×1080；没有视频时沿用工程设置。模板的左右边距和字距按宽度换算，字号、上下边距不变；集预览、观剧点选、注音、歌曲特效、字体检查和导出一致。

文件 → 样式模板：字体、颜色和位置…（新建工程时也会出现）。左边调数值，右边是 libass 渲染的真实画面：

  • 字体、字号、粗体、字距；文字 / 边框 / 阴影颜色（预设配色或调色板任选）、边框宽度和透明度。
  • 每一行的位置（距底边 / 距顶边）、振假名和拼音字号、两人同时说话、屏幕顶部、歌词（唱到 / 未唱的颜色）。
  • 「两人同时说话」和「屏幕顶部」各有一个「字和边的颜色互换」，分别只管 CN.Alt / JP.Alt 和 CN.Top / JP.Top。以前的方案只有一个开关，打开模板时顶部沿用原来的设定，改了以后两者各自保存。
  • “振假名上下微调”“拼音上下微调”：全工程通用，单位为 1080p 像素，范围 −40 到 +40、步长 0.5，正数离正文更远，负数更近；随模板保存，换字体预设或读入样式时保留，预览、观剧点选、导出和自动排位置同步更新。
  • 预览场景：对白 / 两人同时说话 / 屏幕顶部 / 歌词；使用中性例句，随原声与翻译语言切换，其他语言用英语。振假名只在日语侧显示，勾选“拼音”时只在中文侧显示。
  • 没有视频时默认“深色渐变（接近画面）”，工程有带视频的集时默认“这一集的视频画面”；还能选“浅灰渐变”、黑、白或图片。4:3 等视频按显示比例完整预览，字幕用这一集的坐标，两边或上下留黑，不裁成 16:9；勾选“放大字幕区”时显示局部放大画面。
  • “按发布版的间距自动排位置”：用实际测量把各行排到和发布版一样的间距。
  • 字体没装、缺字只提示，从不替你换字体。换模板会写成新版本文件，旧版本保留。

添加一集与合并

读取原字幕、重新分析和合并（含 LaBSE）在后台运行。进度窗口「正在添加这一集…」显示正在读取翻译／原声字幕、正在对齐、正在用语义模型对齐（第一次较慢）、正在保存。主窗口仍可拖动、看列表；添加、合并、重新分析、切集和切工程暂时不可用，菜单标明「（正在添加一集）」。为避免文档冲突，编辑和保存也暂时停用。

点「取消」后在步骤或逐行处理之间停止，提示「已取消，这一集没有改动。」；取消不写工作文档，已有文档保持不变，原字幕副本留着。保存开始后完成这次保存。关闭主窗口先询问取消，最多等待 2 秒再关闭。进度窗口 F1 打开本节，快捷键不变。

集编号例如 S01E017；视频可以不选，以后再加。选视频后，音轨选择原声那条，波形和自动调轴使用它。程序按同目录同名字幕的语言后缀（.zh-Hant、.zh-Hans、.chs、.cht、.ja、.jp、.en 等）匹配工程语言，唯一匹配会自动填入并注明「同目录找到的，可以换」；猜不出时占位列出候选，手动选择。不会覆盖已选字幕。缺集编号或两份字幕时，红字「还缺：…」列出缺项，「确定」灰掉。

翻译样式表按样式名猜内容，可改为「对白」「顶部对白」「歌词（原文）」「歌词（翻译）」「屏幕字、制作名单等（原样保留）」。合并设置中语气词默认全部显示，也可把未翻译的独立语气词藏进可恢复备注。本机有 LaBSE 时可以用语义模型辅助配对，首次较慢、不联网；没有时说明原因并灰掉。

字幕组把一句翻译拆成几行、原声（比如日文 CC）只有一行时，合并设置里选怎么配：「每行翻译各自成组，原声只跟第一行」（推荐，默认）——原声整句留在第一组，后半段用「结尾一段 → 下一组」（Alt+↓）交给下一组；「原声在空格和标点处自动切开」——按各行翻译的时长在断句处切，语序不同时会切错；「配成一个多行组」——以前的做法。拆开的、带原声的组标「边界拿不准」，在列表里用「需要处理」筛选就能找到。整季导入用默认做法。

「合并完成」按组显示这一集的对白（两边都有、只有翻译、只有原声）、歌曲和屏幕字等数量；歌曲与屏幕字本来就不一定配对，零项省略。只有一种语言的对白会提示检查；点「只看这些组」关闭结果框，并把主窗口的列表筛选切到「只有一种语言的对白」，只显示有一轨可见正文的对白，注释和空文字不算正文。逐字去向保留在默认折叠的「详情」里，点击展开或收起；有缺字或重复仍会标红。点「开始编辑」关闭。「工具 → 检查 → 顺序、原文去向、待办」显示相同中文统计，并逐条列出时间、顺序／没有着落／重复／内部数据类别和台词开头。重新分析按原声语言显示标记数量的前后变化。两种结果框的帮助和 F1 打开本节。

  • 集 → 添加一集…：选视频（可选音轨）、翻译字幕和原声字幕（ASS / SRT / SSA）。翻译字幕里的每个样式要确认用途：对白、顶部对白、歌词、屏幕字、注释。
  • 私有功能开启时：集 → 自动导入整季…／集 → 自动导入整季（双语字幕）…：把一季导入当前工程，沿用工程模板；详见自动导入整季。
  • 集 → 合并（生成工作文档）…：保序配对。两份字幕的时间有整体偏移、逐渐漂移、速度差或中途跳变时，合并会逐段跟踪时间差，「合并完成」框列出整体时间差和剪辑不同的位置。
  • 语气词默认全部保留；可选简洁模式（没有翻译的独立语气词放进同组可恢复的备注，组上有标签，随时恢复显示）。
  • 整集重新合并会重新配对，并替换改过的字、读音、隐藏、配对和手调时间；删除过的原文不会回来，说话人保留。当前文档先保存并备份。已经有确认过的配对时，不能整集重新合并。

组编辑区标题「第 n 组 · 状态 · 类型」右侧是工程的快速颜色。点色块给选中的字上色，没选就是整行，和「颜色」按钮一样一步撤销；两处编辑框共用一套，详见快速颜色。

审片与配对

组编辑区从上到下是：上一组文字、标题与快速颜色、正文、操作区、三个工具分区、下一组文字。上下文各用一行灰字显示，太长时省略，悬停可看全文；正文区保留说话人、「整组同一人」、翻译、原声与振假名、拼音及缺语言补行框的原有顺序。

操作区的「分界」保留四个完整名称按钮：「开头一段 → 上一组」「结尾一段 → 下一组」「拿回上一组结尾一段」「拿回下一组开头一段」。下方是「合并」「拆分」「解除配对」及可勾选的「隐藏」「标记」，右侧主按钮为「✓ 确认并下一组」。窗口窄时按组换行，按钮文字不截断；纵向空间不足时可在编辑区内向下滚动，不出现横向滚动条；「合并」「拆分」悬停显示完整命令名和当前快捷键，改键后同步更新。

点击「格式」「ASS 标签与旁注」「位置」标题展开或收起，各自记住上次选择；首次默认只展开「格式」。没有选中字幕组等不适用时，标题显示原因并收起，条件恢复后回到上次展开状态。Tab 按正文 → 操作区 → 工具区移动；Enter 提交、Esc 撤回当前输入、恢复显示与注音操作照旧。

列表右键按播放、确认、复制与时间、补行、转换与 K 轴、隐藏与标记、重复段落、删除排列。只显示当前适用的项目，快捷键显示在右侧；选中的组里原声和翻译都有时，才出现「删除」子菜单的「只删原声」「只删翻译」（只有一种语言时，用「删除这一组」即可），「删除这一组（原声和翻译都删）」始终在最下面。隐藏和标记详见隐藏、标记与复查清单。

复制一组

在编辑模式的列表里右键，选「复制这一组」；多选时显示「复制这 n 组」，每组各复制一份，插在各自原组正后面。对白、歌曲、屏幕字均可复制，整组的内容、开始和结束、语言、角色、说话人、样式、位置、整行与局部格式、旁注和 Raw 标记相同；振假名、拼音以及歌曲的分拍、拍时间、K 轴特效一起复制。

副本里的字作为新手打文字保存，原字幕的去向只登记原组一次。翻译拍对原声拍的吸附链接不复制，拍时间保持相同。新组未确认，不带隐藏、标记或标记备注；复制后选中新组。若正在只看隐藏或标记，自动切回「全部」以显示副本。一次 Ctrl+Z 撤销整次复制。

复制原字幕组，或整段改写源字幕文字而需要单独保留来源样式后，保存的这一集需要用 0.22.0 或以后版本打开。首次保存前会留下升级前的 document.v1.bak.json（同名存在时另存带序号的文件）；回退旧程序前，请先备份整个当前工程，再使用升级前的备份。

选中一组或多组后，列表右键或时间轴菜单的「整体平移…」一起移动时间和 K 轴，详见整体平移。

只选一组时，列表右键「设置开始和结束时间…」可精确输入时间，详见精确设置时间；多选时该项显示「（只能对一组设置）」并灰掉。

列表中 Ctrl+点击切换单行选中状态并切换当前组，Shift+点击扩展范围；当前行和波形／观剧标记即时更新，快速连点停下后合并刷新编辑区。点击、延迟刷新和播放跟随保持列表滚动位置及多选范围。播放跟随只移动当前组。

切换列表筛选条件会保留正在编辑的组；切换卡拉 OK 布局会保留有效的选拍并同步 K 工具条，快捷键不变。

播放与逐段播放

播放菜单或波形工具条上的「逐段播放」开关（Ctrl+Shift+Space）会记住状态。开启后，暂停时按 Space：播放头在对白或歌曲组内，就从当前位置播到组结束前一帧，仍选中这一组；已在结尾或空白处，就播到下一组完全显示时停下并选中。正在播放时按空格照常暂停，打字时空格归输入框；关闭开关后空格照旧，Ctrl+Space 始终播放／暂停。

组内范围为开始至结束前一帧再减 10 毫秒（不含后端）；重叠时优先当前选中组，否则与跟随播放同样选组。下一组是开始时间晚于播放头的第一组；没有时提示「已经是最后一组」。卡拉 OK 模式只看歌曲。

完全显示时间按预览字幕里的原声、翻译、振假名、拼音和特效事件计算：只取最早开始后一帧内或提前出现的事件，忽略后续高亮和晚出现的另一行；取淡入（\fad、淡入方向的 \fade）及起始不晚于 300 毫秒的透明度渐变 \t 的结束时间。每个事件最多计 2 秒且不超过事件长度，最终限制在组开始和结束前一帧之间；预览不可用时用行自己的标签，没有淡入则用组开始。

停下会把播放头放回停止点，选组保持焦点和波形缩放。R、S／Q／W／D／E、Ctrl+Space、点拍播放、Ctrl+←／Ctrl+→ 或选别组会取消本次逐段停止点。在开关或播放菜单上按 F1 可查看播放说明。

补上另一种语言

任何组（包括歌曲）缺原声或翻译时，在列表选中一组或多组，右键选「补上原声（日语）…」或「补上翻译（繁中）…」。名称随工程语言变化；全部已有该语言时，菜单灰掉并显示原因。

单组打开「补上原声（日语）」小输入窗，输入后按 Enter 或「补上」完成；「取消」不改字幕，「帮助」和 F1 打开本节。窗口支持输入法。组编辑区也有空输入行：「这一组没有原声（日语），在这里输入后按 Enter 补上」。观剧模式选中缺语言的组，画面在该语言本来的位置显示「＋ 补上原声（日语）」按钮，点它打开同一输入窗；双击空白处仍退出观剧模式。

多组输入窗每组一行，列为「时间」「翻译（繁中）」「原声（日语）（输入）」；已有文字只读，已经有目标语言的组不列出，上方显示数量。点「从剪贴板粘贴」或在第一输入格按 Ctrl+V，可按列表顺序分配多行，空行跳过。数量不一致时显示「粘贴了 {a} 行，选中了 {b} 组：多的没有用 / 少的空着」。留空的行不补。按「补上」应用全部填写的行。

补上的文字有自己的插入身份，可以编辑和删除；来源字幕不变。开始、结束时间取已有行，样式取模板对应语言的对白／歌曲样式，歌曲行仍是歌词。日文自动生成振假名，中文按工程拼音设置生成拼音；自动读音可以修改。一次补上（包括多组）是一步撤销，记录为「补上原声（日语）」或「补上翻译（繁中）」。

布局

组编辑区按正文、操作区及当前展开的工具分区所需高度保留空间，原文／人物面板只用剩余空间；人物面板空间少时内部滚动。振假名预览与原声输入框各占一行。

视图 → 布局 提供视频优先、列表优先、左右分栏三种布局；卡拉 OK 从视图 → 卡拉 OK 模式（F9）进出。四种布局立即切换并记住选择，各自记住拖过的分隔条位置。

  • 视频优先（推荐）：默认布局。左上是大视频和下接的同宽波形，右上是组编辑区，下方全宽列表约 7 行。原文、人物面板默认收起，打开时以标签页放在右栏编辑区下方，不挤占列表。没有保存过分隔条时，窗口显示后按视频区实际高度适配 16:9 列宽（限制为总宽的 40%–65%）；拖过分隔条后沿用你的尺寸。
  • 列表优先：左上视频约 640×360，右上波形和组编辑区，下方列表约 12 行。
  • 左右分栏：左栏上视频、下列表，右栏上波形和组编辑区、下原文/人物标签页。
  • 卡拉 OK：F9 进出，左栏视频和歌曲列表，右栏放大的波形与精简歌词编辑；详见卡拉 OK 模式，该菜单项的 F1 打开卡拉 OK 节。

主工具栏从左到右是「集」下拉框、「列表」筛选下拉框，接着按分隔线分成「保存」「撤销」「重做」；「播放 / 暂停」「✓ 确认并下一组」；「看片打轴」「全屏观看」「卡拉 OK」；「原文」「人物」。按钮只显示文字，悬停提示显示名字和当前快捷键；在工具 → 快捷键…改键后提示立即更新。三个模式按钮和两个面板按钮的勾选状态与菜单同步。窗口窄时，被挤出的项目可从工具栏右侧的「»」打开。

工具栏的「原文」「人物」按钮可开关面板，视图菜单原有开关也可用。升级首次启动会采用视频优先，此后记住你的选择。进入、切换并退出 F10/F11 后恢复原布局和分隔条位置。布局菜单中按 F1 打开本节。

原文、人物面板的浮动与停靠

标题栏右侧「浮动」使面板成为浮动窗口；浮动后按钮变为「放回右侧」。双击标题栏同样切换浮动与停靠；拖动标题栏仍可移到其他停靠位置。「关闭」收起面板，可从工具栏或视图菜单重新打开。

视图 → 原文、人物面板放回右侧一键打开并放回两个面板。视频优先和左右分栏中，它们以标签页放在右栏编辑区下方；列表优先中放在窗口右侧。浮动面板使用不透明窗口底色；F10/F11 往返恢复面板状态，重启恢复到屏幕外的浮动面板会移回可用屏幕。此菜单及原文面板的 F1 打开本节；人物面板的 F1 打开人物与说话人。

组列表

按住方向键、PgUp/PgDn 或快速点击换句时，列表高亮立即移动；松开或停下约 0.15 秒后，编辑区、原文、波形、K 轴和视频统一显示最后一组。移动中视频快速跳到关键帧，停下后精确定位。输入文字、读音弹窗、就地编辑、自由变换和打 K 轴时保持立即更新。

  • 工具栏“列表”筛选：全部 / 只看对白 / 需要处理。
  • 标签：只有翻译、只有原声、多行组、句中切分、读音?、未渲染语气词、不显示（时间不对的行）等。
  • Shift / Ctrl 多选；Del 删除选中的组（先确认，一步撤销）；右键「播放这一组」、确认这一组 / 取消确认、复制、设置时间、整体平移、补行、AI听译、「转为 ▸」中的歌曲（K 轴）… / 普通台词… / 屏幕字…、隐藏与标记、记为重复段落；最后是删除。
  • PgUp / PgDn 上一组 / 下一组；播放 → 播放时列表跟随 包括对白和歌曲，K 轴工具跟随当前歌曲。重叠时取开始最晚的组，同时间对白优先；多选时只移动当前组，保留已选行。文字框里有还没按 Enter 的改动时暂停跟随，按 Enter 或离开文字框后恢复。
  • 右键已选行保留多选，菜单操作作用于全部选中组；右键未选行改为只操作那一组。「转为」只列可以转换的类型，不可转换的原因放在子菜单的悬停提示里；没有可转换类型时不显示。选中组中有歌曲时出现 K 轴相关项；混合选择时只处理其中的歌曲。补上原声／翻译仅在有组缺少对应语言时出现；AI听译仅在选中对白或屏幕字时出现，条件不足时灰显并说明原因。主菜单也会提示「先打开一集」或「先在观剧模式里点选一行字幕」。

屏幕字与普通台词互转

字幕组误把对白做成带位置的屏幕字时，选中它，列表右键或字幕 → 转为 → 普通台词…：使用工程的翻译／原声对白样式和默认位置，原声按普通台词生成读音，并参与配对、说话人、自动调轴和建议时间；没有说话人时显示「?」。来源的定位、移动、对齐、旋转中心和页边距不用于输出，原字幕不变。

字幕 → 转为 → 屏幕字…恢复来源样式和位置，不提示说话人。两项都支持 Shift／Ctrl 多选，一次转换一步撤销；歌曲要先转为对白才能转为屏幕字，说明和注释不转换。手改的文字、读音、时间和来源身份保留。

AI听译：只有中文时补日语原文

窗口内 Enter 不采用候选，点「补入原文」才生效；Esc 取消并等待识别停止，F1／帮助打开本节。

选中一组有中文、没有日文的字幕，列表右键选「AI听译…」。对白和屏幕字都可以；一次处理一组，已有日文时不会覆盖。程序从本集当前音轨截取附近声音，在后台生成日文候选，不把中文译文翻成日文冒充听写。

顶部「听译状态」醒目显示正在听译、正在停止、完成或失败，显示已用时间及真实处理步骤，例如加载模型、分离人声、识别原声／短窗。忙碌条表示仍在处理，不代表完成百分比。处理期间候选和时间暂不可编辑；点「停止」后会等待后台退出。

勾选「根据中文另列日语候选（语义推测）」后，也会用免费本地中译日模型生成几个可能的日语说法；默认开启。它们标注为「语义推测（未确认）」，可在「查看」选择全部、音频识别候选或中文语义推测。中文字幕只交给独立翻译模型，不交给 Whisper 作为听写提示；「听到的词」仍仅供填写实际听出的日语。语义候选可能与配音用词不同，不能当作已听出的原句。

  1. 打开后自动开始。默认向前后各扩展 1200 毫秒，短句的上下文至少扩到 3 秒；也会另试目标时间前后各 300 毫秒的短窗，短窗候选会标注更易幻听。可以修改「前后各扩展」（0–5000 毫秒）、模型和「同时尝试人声分离」，再点「重新听译」。如果已听到某个日语词，可在「听到的词（可选）」填写，例如「ふうせん」；程序保留无提示识别，并另试人工提示词，结果会标注提示词来源。提示词不保证有效，也可能被模型复述，仍须听音核对。
  2. 候选按时间和来源去重，显示来自原声、声道、人声分离还是消声残余。同一句可能来自多种处理；来源多不等于正确率。与附近已有日文相似时提示可能仍是前景声，消声／短窗／依据弱的结果也会提示。
  3. 点「试听原声（扩展范围）」听整段，或选中候选点「试听所选候选」听该处理音频的对应范围；「停止试听」立即停止。可以修改日文和开始／结束毫秒数，时间须在本次试听范围内。没有候选时仍可试听后手动输入。
  4. 候选不合适或太少时，点「更多翻译建议」。程序根据同一句中文换一轮生成，避开已经列过的说法，只追加去重后的新候选，不重新识别音频。旧候选、正在编辑的文字和时间保持；停止或失败后仍可使用旧结果。若本轮没有新说法，会明确提示，可以再试或手动修改。招呼、提供物品等语义也会考虑合适的礼貌句式，仍不能保证每轮数量或原台词。
  5. 语义候选的试听使用原音，时间先沿用所选中文字幕，没有经过语音对齐。请边听边比较、修改；选择和试听本身不表示程序已确认这句话。即使听写结果与语义候选相同，也分别保留来源。
  6. 确认后点「补入原文」。新增一条日语对白并生成自动振假名，使用模板日文对白样式和你确认的时间；原中文、原位置、格式、分类和时间保持不变。背景声可能与已有对白重叠，采用后仍可用现有位置／说话人工具调整。一整次采用可用 Ctrl+Z 撤销。

听译期间可以继续编辑其他句子；目标句、视频、音轨或工程改变后，旧结果禁止采用，请重新打开。点「停止」可取消当前识别；重新听译、关闭和换集都会等待旧进程停止后再清理临时音频。Esc 关闭并取消，Enter 不会直接采用，F1／帮助打开本节。

这是听写辅助。声音很轻、两个人同时说话时，候选可能全是较响的前景对白或幻听；人声／音乐分离也无法保证把两个说话人分开。怪人 EP03 13:26–13:31 的「要氣球嗎」「很好玩喔」实测尚未恢复，不能仅凭模型结果认定已经补全。请先听后用。

本机识别环境

语义候选复用本机已有的 Qwen3.8-27B 量化语言模型和 llama.cpp，不使用付费 API。只给模型选中中文字幕，用单轮独立进程尽量生成6至8个日语说法，优先常见表达，并覆盖措辞、句式和口气差异；只改标点／空格的重复项会合并。合理表达不足时允许少给，不为凑数改变意思。模型没有工具，结束即退出，不启动常驻服务，不改变通用 Agent 的默认模型路由。大模型加载可能较慢，可随时停止；缺模型或翻译失败时保留音频候选。

本地翻译使用已配置的 GGUF 模型与 llama.cpp CLI。通过 SUBKIT_TRANSLATION_GGUF／SUBKIT_LLAMA_CLI 环境变量，或程序目录内不入 Git 的 duosub.local.json 设置实际路径；同名环境变量优先。其他模型／CLI 版本需验证兼容性。界面不自动下载模型，不修改全局 Python；推理输入限制6000字节、上下文2048、单次240秒，保留取消／关闭保护。CPU也可运行，但可能较慢。

使用已安装的 Whisper medium／large-v3 和可选 Demucs htdemucs；优先用可用 CUDA，实际设备显示在结果中，模型在独立进程加载，缺少时明确报错，不自动联网下载。当前机器复用 E 盘现有 GPU 包；其他机器可用 SUBKIT_ASR_PYTHON 指定 Python、SUBKIT_ASR_PACKAGES 指定补充包目录、SUBKIT_ASR_MODEL_DIR 指定包含 medium.pt／large-v3.pt 的目录，Demucs 缓存使用 TORCH_HOME。不需要改系统链接或其他工具的环境。

采用记录保存在新增日文的工程数据内，包含原始候选、采用文字／时间、处理来源、模型和设备；语义候选还保留参考中文、生成轮次、模型及「未经音频确认」记录。机器结果具有插入文字身份，不伪装成导入字幕。关闭候选窗清理临时试听音频，不保留无效临时文件路径。

隐藏、标记与复查清单

右键的确认／取消确认、隐藏／取消隐藏、标记／取消标记按当前状态只显示适用的一项；多选状态不一时两项都显示，各自只改变需要处理的组。「编辑标记备注…」仅在选中组中有标记时出现。快捷键 Ctrl+H 隐藏、Ctrl+M 标记；「只看已标记」「只看已隐藏」可筛选复查。

在列表用 Ctrl／Shift 多选，右键「隐藏（不显示、不导出）」或「取消隐藏」。组编辑区底部「隐藏」开关反映当前组状态。隐藏组留在工程里，文字、时间、读音和说话人保持原样；预览、观剧模式和发布用 ASS 中完全不出现，也不写成注释行。导出报告显示「隐藏的组：{n} 组（没有导出）」。取消隐藏恢复显示和导出。

隐藏组灰显并显示「已隐藏」标签。建议时间和自动调轴不把它当邻组，自动调轴不会改变隐藏组。列表筛选增加「只看已隐藏」和「只看已标记」。

右键「标记待复查」「取消标记」「编辑标记备注…」，或点击底部「标记」开关。标记只用于复查，不影响显示和导出；标签「★ 标记」的悬停提示包含备注。备注窗口为单行输入，多选时写入所有选中组，留空清除备注。隐藏、标记、备注各自一次操作一步撤销，保存并重新打开仍保留。

文件 → 导出 → 标记和隐藏的句子…先保存当前集，再从磁盘读取工程所有集的工作文档。默认保存到工程目录的「复查清单-{时间}.html」，旁边生成同名 CSV（UTF-8 带 BOM）。HTML 按集号和标题分节，列出组号、开始–结束、翻译、原声、状态（标记／隐藏／标记+隐藏）和备注，单文件无外部依赖，随系统浅色／深色模式显示。没有待复查句子时提示「工程里没有标记或隐藏的句子」。导出后询问「用浏览器打开吗？」。

Ctrl+H 隐藏／取消隐藏，Ctrl+M 标记／取消标记。备注编辑和复查清单导出无独立快捷键；菜单、开关及备注／保存窗口的 F1 打开本节；Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Esc 取消窗口。

已分析过的对白组可用精确对话轴（按台词对齐）改善提示线和 C 键建议；图例显示建议来源。未对齐的组继续按人声能量判断。

打轴（波形）

工作文档的开始、结束时间不小于 0；合并对齐、自动调轴、整体平移和手动改时间产生负数时，两端分别夹到 0。整行在 0 之前时成为 0:00–0:00，导出为注释，报告仍列入「没有时间的行」。打开旧文档也会修正并记为待保存，不增加撤销步骤；来源原时间不变。

波形工具条按「视图」「播放」「打轴」「设置 ▾」分组，组间有竖线，放不下时整组换行。「视图」包含「波形」「频谱」、标为「缩放」的滑块、「可见 {n} 秒」「适合本组」；「播放」包含「速度（对白）」／「速度（歌曲）」下拉和「逐段播放」；「打轴」包含「显示提示线」「采用建议时间」。其余操作位于「设置 ▾」：「设置 ▾ → 振幅」调整滑块（Shift+滚轮仍有效）；「设置 ▾ → 打轴对象」选择整组／只改翻译行／只改原声行；「设置 ▾ → 吸附」「设置 ▾ → 吸附到提示线」「设置 ▾ → 建议提前量」「设置 ▾ → 跟随播放」「设置 ▾ → 钉住」「设置 ▾ → 重新读取音频」。勾选、记住的状态和快捷键沿用原规则，菜单项 F1 打开对应说明。

工具条最右的「?」悬停显示当前打轴方式的操作提示，点击切换下方灰色提示行是否常驻；默认显示，选择记在本机，重启后保留。图例行仍由「显示提示线」控制。「?」上的 F1 打开本节。

「设置 ▾ → 频谱配色」选择频谱的颜色：「深海青（推荐）」（默认，深色背景上的青绿色，长时间看不刺眼）、「柔和灰」、「暮光」（强弱层次最分明）、「色盲友好」、「经典蓝绿黄」（以前的配色）。选择记在本机，所有工程通用。同一菜单里有「对比度」「亮度」两个滑块：对比度把背景噪声压暗，亮度把中等强度的声音（人声谐波）提亮，默认对比度 50、亮度 60；「恢复默认对比度和亮度」回到默认值。

读取音频失败时，点波形区中间的「重新读取音频」或「设置 ▾ → 重新读取音频」丢掉本集波形缓存并重算；悬停错误文字可查看完整命令和错误。放大细节读取失败时继续显示粗波形与频谱。

常驻工具条上的「速度（歌曲）」／「速度（对白）」下拉分别记住歌曲速度和对白速度，默认都是 1×；换组自动切换，卡拉 OK 模式始终使用歌曲速度。音高不变，打拍时间仍按原速记录；速度不是 1× 时，状态栏显示「{速度}× 播放」。

F9 进入卡拉 OK 模式后，左键选中歌曲色条，点拍选中并跳到拍开头，点空白只移动播放头；右键点拍播放这一拍，拍外不做事。对白色条和调轴点击停用；退出后恢复原打轴方式和缩放。

打开「显示提示线」时，工具条下面显示带颜色小样的图例及当前提前／延后毫秒数和来源；关闭时隐藏。按能量判断时，每个对白组只显示离组开始／结束最近的一对人声边界（各在 ±600 毫秒内），当前组完全不透明，其他组 45% 不透明；歌曲起音／收音照旧。滚动、改轴和采用建议后仍持续显示。有有效台词对齐结果时，图例显示「建议来源：按台词对齐」，人声开始／结束使用对齐边界（见精确对话轴）；否则图例显示「建议来源：按人声能量」，人声开始/结束按声音能量估计，已减少背景音乐下跨过短暂停顿的误合并，但仍可能不准，请试听确认；建议时间 = 人声开始前提前一点、人声结束后延后一点，不会和前后组撞车。

「设置 ▾ → 建议提前量」有四种模式，选择记在工程里，默认「按我调过的行（推荐）」：只用本工程对白组中由你拖动、点击或输入改过的开始／结束端计算；只手调开始，未改的结束就不参与。采用建议时间和自动调轴的端不参与学习，即使组已确认也不计。已确认组中没有来源记录的端视为人工确认；旧文档只有手调标记、没有分端来源记录时，两端都按手调计。歌曲、屏幕字和仅改过文字的行不参与。用本集已加载音频及其他集已有的波形缓存，开始和结束各至少 20 组有结果时，取最近人声边界与字幕时间之差的中位数，图例显示「按我调过的行算出」，并更新本机的“我的习惯”。

可靠样本不足、其他集没有可用波形缓存时，使用本机保存的“我的习惯”，图例显示「按我的习惯」。习惯不随工程保存，可跨工程沿用；首次初值为提前 100 毫秒、结束后 160 毫秒，由少女革命十集和 Overlord 六集成品的有效样本实测合并得到。打开／切集后音频就绪时算一次，改轴后不会实时重算；点「设置 ▾ → 建议提前量 → 重新计算」更新。提前限 0–600 毫秒、延后限 −200–600 毫秒。

「设置 ▾ → 建议提前量 → 按本集字幕」用本集全部对白的现有时间算，适合整体校正字幕组的轴；开始和结束各至少 20 组有结果，否则使用工程上次算出的值，再没有则使用自动调轴设置。图例显示「按本集字幕算出」或「同自动调轴设置」。旧工程没有主动选择过模式时改用新默认；明确选择过「按本集字幕」、自动调轴或固定值的工程保留选择。

选「设置 ▾ → 建议提前量 → 同自动调轴设置」使用自动调轴「详细设置」的提前／延后；选「设置 ▾ → 建议提前量 → 固定值…」打开小窗填写提前、延后（毫秒），「确定」保存到工程，「取消」保留此前选择，图例来源为「手动设定」。小窗的「帮助」和 F1 打开本节。

当前对白组的白色建议线与「采用建议时间」（C）使用同一组提前／延后值。只找到开始就只画「建议开始」，只找到结束就只画「建议结束」；采用只改有建议的那一头，另一头保持当前时间，只改当前对白组，一步撤销，记录为「采用建议」，仍受自动调轴的手调保护。音频、提前量和邻组不变时，连续按两次 C 不会再次移动时间；撤销／重做同时恢复每一端的来源。建议开始不早于前一组结束，建议结束不晚于后一组开始（按时间相邻的对白或歌曲组，使用当前时间），可以首尾相接；原本重叠的一侧不夹取，夹取后与未改动的一头组成的结束不晚于开始则不提供建议。

搜索锚点为「当前开始 + 提前量」和「当前结束 − 延后量」，找离锚点最近的人声边缘。人声从这一组一直连进下一组、中间没有检测到停顿时，在结束锚点前后各 300 毫秒内找能量最低点作为人声结束；从上一组连过来的开始同理，以开始锚点为中心。再应用所选提前／延后值，并按邻组当前时间夹取。原本重叠的两组不自动切分人声。开始／结束搜索为锚点 ±600 毫秒；采用后仍会继续漂移的候选不提供建议。校准提前量只统计检测到的边缘，导入吸附仍独立处理两头。

「设置 ▾ → 吸附到提示线」保留原「吸附到起音」的选择。左／右键设对白开始／结束、拖组边界时分别只吸附到这一对线中 6 像素内的人声开始／结束，省略的其他人声段边界不吸附；与「设置 ▾ → 吸附」的画面切换线、相邻行边界取最近目标。Aegisub 式按 Shift，点块选中方式按 Alt 临时不吸附。显示和吸附可分别使用。

工具条最左边的「波形」「频谱」按钮切换显示，记住上次选择；工具条放不下会按组整体换行，组内控件保持一行，按钮文字完整显示。选组只平移，不改变时间缩放；长组的开头放在视野左侧约 10% 处。点「适合本组」按本组长度缩放，两边各留 20%（受最小 1 秒、最大 120 秒视野限制；音频开头不能向前留白）。

刻度分为带时间文字的长刻度和不带文字的短刻度；放大后短刻度可细到 10 毫秒，时间文字显示到百分之一秒，按字宽调整间隔，避免重叠。

可见范围短于 6 秒时，波形按每个像素列显示采样的最大／最小值并连接；频谱在后台按约 2 毫秒的时间步长计算，低频在下方，颜色含义不变。放大到约 1 秒更容易看清波形和起音边缘。计算完成前先显示原图；已有音频缓存的集，首次放大时会在后台读取音频，稍等便显示细节。

精确设置时间

编辑模式里只选一组，列表右键「设置开始和结束时间…」。窗口「设置开始和结束时间」预填本组当前时间；「开始」「结束」接受 0:01:23.45、精确到毫秒的 0:01:23.456、分:秒 1:23.45，或纯数字毫秒（如 83456）。工程保留毫秒精度，列表仍按厘秒显示；重新打开窗口会保留第三位小数。

「作用于」可选「整组」（默认）、「只改翻译行」或「只改原声行」，没有对应语言时该项不可选。歌曲组已有 K 轴时显示「K 轴拍跟着开始时间一起挪」（默认勾）：按每行自己的开始时间变化平移被改行的拍；只改一种语言不会带动另一种语言。手动平移的拍解除原声拍吸附，避免以后被吸回。取消勾选时拍的绝对时间不变，超出行界仍提示「有拍落在这一行的时间外」。

格式错误时红字「时间格式：0:01:23.45」；结束不晚于开始时红字「结束要晚于开始」，均不能确定。确定后两端记为手调时间，后续自动调轴默认保护；一步 Ctrl+Z 撤销「设置时间」。取消／Esc 不改文档，帮助／F1 打开本节。

整体平移

在列表选中一组或多组，右键或用时间轴 → 整体平移…。小窗显示「把选中的 {n} 组」，选择「提前」或「推后」，输入毫秒数（0–600000，箭头每步 10 毫秒，记住上次确定的值）。「确定」一起移动所有行的开始、结束和 K 轴的拍，文字、读音、配对保持不变；「取消」不修改，「帮助」和 F1 打开本节。

提前超过最早一行的开始时间时，提示「开始和结束都夹到 0」，仍可确定。一次操作只需一次 Ctrl+Z 撤销，记录为「整体平移 {n} 组」。这些行记为手动调过时间，自动调轴默认不再移动。

波形「设置 ▾」内的振幅、打轴对象、吸附、吸附到提示线、建议提前量、跟随播放、钉住没有新增快捷键；原有滚轮操作与 F10／F11 照旧。K 轴「更多 ▾ → 歌词」含「对应…」「英文按音节拆开」「读入原字幕的 K 轴」，「更多 ▾ → 特效」含效果选择与「参数…」；F1 分别打开 K 轴与特效章节。

统一两种语言的时间

合并时配对的组用翻译字幕的时间，原声行跟着；没配上的原声行按两份字幕的时间差挪到翻译的时间线上。如果原声字幕更准（例如 BD 原版日文字幕），可以改用原声的时间：

  • 时间轴 → 统一两种语言的时间 → 用原声字幕的时间：对白回到原声字幕文件里的时间，同组的翻译行拉到同一段时间（同组有几行翻译时保持先后和比例）；没配上的翻译行按附近配对组的时间差一起挪。
  • 时间轴 → 统一两种语言的时间 → 用翻译字幕的时间：反过来，对白回到翻译字幕文件里的时间（刚合并的一集本来就是这样，通常没有变化）。

只改对白；歌曲（另用「翻译时间对齐原声」）、屏幕字、隐藏的组不动；确认过的组和手调过时间的行不动，结果里写明「确认过或手调过时间的 n 组没动」。一步撤销「统一两种语言的时间」。只在那份字幕本身和视频同步时用：例如剑姬的日文 SRT 比中文字幕整体晚 3–4 秒，改用原声的时间后会和画面差 3–4 秒；不确定时用「时间轴 → 自动调轴（按视频音频）」。菜单的 F1 打开本节。

自动调轴

下载的字幕和你的视频不是同一个版本时（例如 Netflix 的日文 CC 配 BD 视频：前半集差半秒、片中断点之后突然差十几秒；或者字幕慢慢越差越多）， 在已经合并的一集里点 时间轴 → 自动调轴（按视频音频），等音频读完（波形显示出来）后一键完成。

程序按视频里的人声找出每一段字幕差多少（片中断点前后可以不同，帧率不同造成的慢慢漂移也会算进去），然后把整集的组一起挪过去，两种语言保持同一时间。默认不逐行贴合人声。

音频读完后，如果发现可信的整体偏差达到 0.15 秒，或找到这一集还没套用的重复段落，会合并询问一次：「这一集可以自动处理」。列出时间差（有分段时注明片中断点前后不同）和找到的段落，再问「要现在处理吗？处理后都可以 Ctrl+Z 撤销。」音乐盖住人声时可能找不到可信的对应。

  • 只显示有用的按钮：「自动调轴」「套用重复段落…」「先不处理」。自动调轴的结果框照常出现；如果也找到重复段落，关闭结果框后接着打开查找并套用对话框。
  • 同一集在这次打开期间只问一次；勾选「这一集不再询问」会按工程和集记在本机设置里，不改工程文件。仍可随时从时间轴菜单处理。
  • 打字、播放、有对话框或读音/就地编辑弹窗、自由变换、按 K 打拍时先等待，停下来再问；切到别的集就丢弃上一集的待询问项。F10 / F11 中也会在全屏上方询问，处理后保持原模式。
  • 询问框的「帮助」和 F1 打开本节。

结果与撤销

  • 「自动调轴」结果框列出调整的组数、行数、「怎么挪的」各段开头和结尾提前或推后的秒数与把握、「没动的」数量和「对齐结果」说明。确认过的组和手动调过时间的行默认不动；低可信度段、跨断点后时间倒置的组也不动，并显示数量。
  • 差不到 0.04 秒（约一帧）的组不动；整集都是这样时，结果框显示「字幕和视频已经对得上」。
  • 「对齐结果」分两行说明：整体已对齐（调之前最多差多少秒），没改动且本来对得上时显示原来的最大差值；单句质量为好时「各句的时间都和声音吻合」，一般时「少数句子本身的开始、结束时间不太准，自动调轴不改单句」，差时「不少句子本身的开始、结束时间就不准（不是整体偏移），自动调轴不改单句；需要的话在列表里逐句调」。没有把握或受保护而未改动时不会声称已对齐。质量阈值仍为好（不超过 0.08 秒）、一般（不超过 0.2 秒）、差（超过 0.2 秒，或约一半窗口不可靠）。
  • 「撤销」和 Ctrl+Z 撤销本次操作；结果框的撤销只在本次操作仍是最后一步时生效。「关闭」保留结果。
  • 「逐段查看和调整…」先撤销刚才的一键结果（仍是最后一步时），再按你选的设置显示预览；点「取消」会恢复刚才的一键结果，点「应用」换成新的结果。

逐段查看和调整

分段表的「结尾多挪（秒）」显示速度修正导致的额外挪动量。组表显示列表里的组号；底部「对齐结果」使用同样的整体／单句说明，应用前的整体结果明确标为预览。结果框中负时间差显示「提前」，正时间差显示「推后」，秒数保留两位。开头和结尾差不到 0.05 秒时显示「整段」。

「自动调轴 — 逐段查看和调整」里可选参照：对齐到视频的声音（推荐）、原声字幕原来的时间、翻译字幕原来的时间；方式可选整集一起挪、分段挪、分段挪 + 纠正速度（推荐）。缺少所选语言的组按相邻组推算。

切换参照、方式或其他设置后，程序在后台重新计算，显示「正在计算…」。连续调整会稍等后计算，只显示最新设置的预览；计算完成后才能点「应用」，关闭窗口会取消计算。

以字幕原来的时间为参照时，整集也能快速计算；速度修正与剪辑断点仍按证据分段。合并时，即使一种语言长时间缺少对应字幕，未配对内容也会按来源顺序完整保留。

  • 「逐行贴合人声（实验）」默认关，可选只调开始、开始和结束、保持原时长。提前开始默认 0.27 秒，延后结束默认 0.00 秒；程序记住上次的贴合模式和提前、延后值。导入时吸附不产生新的行间重叠：冲突时截短前行结束，不足 300 毫秒则退回原结束，必要时退回冲突的吸附结果；原有重叠仍允许。逐行贴合还会按整份文档的映射后时间检查相邻对白与歌曲组，以邻组计划时间（未调整的组用当前时间）限制贴合边缘，不制造新的跨组重叠；映射后原有的同时说话保留。这个功能效果有限，建议先试听。
  • 屏幕字、注释、带位置标签的行、歌曲行和附近没有人声的行不会贴合，只跟着所在的段一起挪。
  • 勾选「也调整确认过的组和手动调过时间的行」才能调整这些人工成果。旧工程没有手调标记的行只按组的确认状态保护。
  • 分段表可修改「挪动（秒，负数=提前）」；选中一段并点「和上一段合并」，把它并入前段（选第一段时删除其后的断点）。设置变化后重新预览。
  • 逐组列表显示原时间 → 新时间和时间差；低可信度的组默认不勾。选中一组点「试听」会从预览的开始时间播放；勾选要调整的组，再点「应用」，仍是一步撤销。
原字幕的字节、文字和原时间永远不变。K 轴拍跟着映射平移或缩放。在结果框或逐段查看和调整中按 F1，或点「帮助」，打开本节。

Z 打开这一组翻译的就地编辑框，X 打开原文的，位置和双击字幕相同。「这一组」优先用画面上选中的组；没有选中时用当前时间显示的组，同时显示多组时用列表当前组，没有显示组时也用列表当前组。非空行不在画面上时先跳到这一组开始；空白行的对应组仍在画面上时保持当前时间。对白只有译文时，按 X 自动补空白原文并进入编辑；只有原文时，按 Z 自动补空白译文并进入编辑。新行沿用工程语言与补行样式，时间与对面行一致，已有对应行不重复创建；即使预览尚未生成或没有字幕外框，也能立即输入。Enter 提交文字；Esc 放弃本次输入，空白行保留，Ctrl+Z 可撤销补行；提交后的文字编辑与补行各自沿用普通撤销步骤。歌曲、屏幕字和信息组缺行时仍提示缺少该轴。正在打字（任何输入框有焦点）、有弹窗、自由变换或带 Ctrl / Alt / Shift 时不响应；Ctrl+Z 仍撤销。已有编辑框时切到对应行，和 Tab 一样先提交当前文字。

就地编辑标题显示「正在编辑：原声（日语）· 第 2/2 行 · JP」，「正在编辑：」为蓝色（#3EA6FF）。真正输入框为白底（#FFFFFF）、深色字（#1F2328），聚焦时 2 px 蓝框（#3EA6FF），未聚焦时 1 px 灰框（#8B949E）。只有日文行显示振假名预览：深底（#1B1F24）、浅灰正文（#C9D1D9）、淡蓝振假名（#79C0FF），无输入框边框；上方说明「预览 · 点振假名改读音，拖选汉字加读音」（11 px、#8B949E）。格式栏、ASS 标签框与底部提示保持深色。

编辑框打开时，Esc 放弃未提交文字并关闭，焦点回到画面，保持当前观剧模式；焦点在输入框、ASS 标签框、格式栏或编辑框外都有效。读音弹窗、字体下拉等先关闭。编辑框关闭后再按 Esc 才取消选中／退出观剧模式。

分词认定为一个词时，连续汉字上的振假名按整词居中、统一计算宽度和缩放；内部读音分成几段不会自动变成多个排版词。需要各段分别排版时，请先用分词工具拆成多个词。原有读音段、歌词拍和人工设置保留；送假名之间分开的汉字注音仍对准各自汉字，不把读音移到无需注音的假名上。

读音弹窗「按单个汉字拆开…」中，Enter 确定逐字输入，Esc 回到原弹窗；输入法组字时 Enter 先确认组字。

读音弹窗并入相邻词后显示新词的候选，优先列出整词的词典读音（如「世間話 → せけんばなし」），再列工程手打历史和各部分组合；点候选或按数字键 1–9 应用到整个新范围，三种作用域照常生效，输入框仍预填各部分拼接读音，还原范围恢复原候选。

自动读音现在能正确识别口语长音（如「お疲れー」「寒ーい」），振假名只落在汉字上，原文保留；人工和已确认的读音不变。

新导入／重新合并时，原声中「汉字 + 全角或半角括号 + 只有平假名」作为原文指定的振假名，即使不是词典读法（如 風（うず）、焔（ひ））；括号不进入正文。片假名括号和说明括号照旧，已有集的人工修改不自动刷新。

批量替换列表（整个 Project）

Tab 切换输入框；输入框内 Enter 不提交整张表，点「保存全部」才生效，Esc 取消草稿。

点「新增」后直接在词 A 输入；单击词 A／词 B 可编辑，Tab 切换输入框。输入时保留当前单元格焦点，同时选中所在行供删除和排序使用。

显示规则 → 批量替换…：用一个列表统一人名、删除已知多余字。每条有「启用」「词 A」「词 B」「作用轴」；可新增、直接修改、删除所选、上移、下移。词 A 不能空，词 B 留空即删除，禁用的条目保留在列表但不执行。作用轴可选原声、翻译或两轴，名称带当前工程的语言；轴和语言是两个属性，不把原声固定当日语。

所有规则都作用于整个当前 Project 的全部集，不同工程隔离。修改先保留在草稿，点「保存全部」才保存并刷新视频；「取消」／Esc 不写入。下方纯文本对照可用当前句或自行输入的例子，不含其他显示规则、样式和注音，也不会写回字幕。

按编辑原文字面匹配，区分大小写，保留首尾空格，不使用正则表达式。每个原文位置优先采用列表靠上的规则，替换结果不会再参与匹配。例如 A→B、B→C 两条，原文 AB 显示为 BC；需要较长词优先时把它移到上方。规则在简繁转换、标点标准化和两行合一之前执行；因此词 A 按编辑框原文填写。

只改变视频预览、F10／F11、单集／整季 ASS 和审议包中的正文。编辑框、源文件、工作文档、来源、人物档案、Name 栏、旁注和存储的注音／歌词拍都不改。可跨普通 ASS 字体、颜色标签匹配，标签保留；不改 Raw／绘图，不跨硬换行，不允许用反斜杠、半角大括号或换行写 ASS 代码。关闭或删除规则即可恢复原文显示。

原有振假名／拼音按对应底字范围移动，不会重新猜读音。词 B 是读法不同的新词时，请在原文编辑区修正读音；删除触及注音底字时，这段注音暂不显示，原注音仍保存在工程。歌词余下的拍保留原时间。替换后无法精确反查的片段不能直接在视频里新增读音，请回原文编辑区；审议导回也不会把这类派生片段直接写入原文。

与「参考原配简繁字幕」一起导出时，匹配到批量替换的行优先保留替换后的正文，不让原配字幕恢复已删字或旧人名；对照报告标为「应用工程批量替换」。普通导出报告列出替换行数、次数和删除字数。窗口／菜单 F1 打开本节，无独立快捷键。

显示规则

显示规则 → 标点方案 → 标点和空格… 打开设定画面。规则只影响预览和导出，原字幕、工作文档和编辑输入不变；设置随工程保存，修改立即生效（视频预览一起刷新），「确定」保留，「取消」或 Esc 恢复打开画面时的设置；不产生撤销步骤。画面和其中按钮的 F1 打开本章。

标点分两层，翻译（{译文语言}）和原声（{原声语言}）各一页：

  • 字符标准化：真的换字，例如「～」→「~」、「——」→「--」。
  • 显示字体：字不换，只指定这一类标点用哪个字体显示。用来解决某些字体把符号画歪的问题，例如手写、圆体字体把长音「ー」画成带笔锋的样子——给「长音」一类选一个长音是直线的字体。
  • 两层各有作用范围：「对白」「歌词」「屏幕字等」。默认字符标准化只作用于对白，显示字体三类都作用（不管这一行原来用什么样式和字体）。以前保存的旧设置里，原来那个「标点字体」只作用于对白，旧工程导出不变。

每页的表格一行一类：类别｜字符标准化｜显示字体（默认「沿用这一行的字体」，可输入筛选；没装的字体标「（未安装）」）｜例子。「全部标点：[字体] 套用到全部类别」一次设好所有类别，之后可单独改。设了字体时，作用范围内这一类的每个标点（换过的和原来就是的）都用这个字体，之后恢复这一行原来的字体。

  • 「半宽假名」：默认“不改”，选择“转为全宽（含长音）”后，ｶﾞ → ガ、ﾊﾟ → パ、ｳﾞ → ヴ、ﾈｲｶﾞｰ → ネイガー，包含半宽长音 ｰ → ー。两种语言分别设置，沿用“字符标准化作用于”勾选的对白／歌词／屏幕字等范围。只影响显示与导出，编辑输入、来源字符和已存的拍不变；合成字按基字的格式显示，后续注音、旁注和 K 轴仍对应原文。此项不另设显示字体，长音可继续使用“长音”一行的字体。
  • 「逗号」（，,）：不改／换成两个空格／换成「、」；数字千分位（1,000）不改。
  • 「顿号」（、）：不改／换成两个空格。逗号先换成「、」时也一起换成空格。
  • 「句号」（。．）：不改／换成两个空格；半角英文句点「.」一律不动（Lv.4、No.1、3.5、a.m.），全角「．」夹在数字或字母中间（３．５、Ｌｖ．５）也不动；「...」按省略号规则处理。
  • 「冒号、分号」（：:；;）和「括号」（（）()【】《》〈〉［］[]）：只设字体。
  • 「省略号」：不改／统一为「…」／统一为「……」／保留个数，换成「…」（连续三个点算一个）。
  • 「感叹号」「问号」：不改／全角／半角，逐个转换。
  • 「引号」：不改／统一为「」／统一为『』／外层「」、内层『』／外层『』、内层「」；孤立引号不变。
  • 「分隔号」：·、‧、•、･、⋅、∙ 统一为「・」；汉字或假名之间的「．」「.」也算（勞爾．諾德 → 勞爾・諾德）。
  • 「波浪号」（~ ～ 〜 ∼）：不改／全角「～」／半角「~」／波浪号「〜」，个数不变；日文里拉长音的「〜」（危な〜い）也换。
  • 「破折号」（- – — ― ─ ━ ‐ ‒ － 和单独出现的「ー」）：不改／半角「-」／全角「—」／长音「ー」／横线「―」／全角连字符「－」，连续几个算一组，个数不变（「——」→「--」）。英文字母或数字之间的「-」（T-shirt、2-3）和接在假名后面的「ー」不算。
  • 「长音」（接在平假名、片假名或另一个长音后面的「ー」「ｰ」：すごーい、ハロー、やったかー）：这一行只设字体；半宽「ｰ」变为全宽「ー」由“半宽假名”控制。原来单独出现或接在汉字后面的「ー」属于破折号；从半宽长音转换来的仍按长音处理。
  • 「空格」：不改／统一为两个半角空格；英文单词之间的单个空格保留，行首、行尾和硬换行两侧的空格去掉。

半宽假名转换只处理假名和浊音／半浊音标记，完整保留其他字符：全角英数、圈号、单位、空格及 ｡｢｣､･ 继续按各自原有规则处理；{@Raw=…} 和 ASS 绘图保持原样。不能合成的孤立浊点保留为可见的全角符号。方案保存、导入／导出和新工程默认包含此选项，旧方案缺少该项时按“不改”处理。

预览：每页有一个可以改的示例，「用当前这一句」填入当前组这一语言的文字，「恢复示例」还原。「预览样式」选对白、歌词或屏幕字，用工程里这一类行的样式，经 libass 渲染「原文」「显示」两行（和导出、样式模板编辑器同一条路），并按这一类的作用范围决定两层是否生效；缺字体、缺字列在预览下方。修改后约 0.3 秒自动重画，后台进行，不卡界面。

歌词行有 K 轴和振假名：显示字体先插入正文，再测量振假名位置，所以振假名按换过字体后的字宽排列；一拍中途换显示字体时，导出的正文和振假名会在标签处拆分 K 轴：扫字按可见字数分配时间，整拍总时长不变；整拍变色效果仍同时变色，标点不会停在未唱颜色。扫字（kf）时括号、问号等标点不占时间：拍开头的「「」在这一拍开始时立刻变色，拍末的「」」在前面唱完时立刻变色；省略号「…」和长音「ー」「〜」算唱的字，照常分时间。有没有换字体都一样，中文和日文一致。振假名本身不换字体。竖排歌词请选支持竖排字形的字体（通常以 @ 开头），长音的竖排样子由字体决定。缺失的标点字体会在「工具 → 检查 → 字体（缺字体、缺字）」和导出检查里列出，导出的字体标签也供字体嵌入使用。

方案（Profile）

方案 = 两种语言的全部字符标准化规则、显示字体和两层的作用范围，保存在本机用户设置目录的 punctuation-profiles\{名称}.json（duosub-punctuation-profile v1），所有工程都能用。工程保存自己的一份设置，只记住方案名，所以删除方案或换电脑不影响已有工程。

  • 画面顶部「方案：」下拉列出已存方案；选一个就套用到当前工程（「取消」可恢复）。工程设置和所选方案不同时显示「{名称}（已修改）」，没有对应方案时显示「（未存为方案）」。
  • 「另存为方案…」（重名时问是否覆盖）、「删除方案」（工程里已用的设置不变）、「导出…」（存为任意位置的 .json，可拿到别的电脑）、「导入…」（重名时选覆盖或改名）、「设为新工程的默认」（新建工程时自动套用，下拉里标「（默认）」）。
  • 显示规则 → 标点方案 列出方案，当前的打勾、改过的标「（已修改）」，点一下就套用——做完特殊番剧后一键切回标准方案；最后一项「标点和空格…」打开设定画面。没有方案时显示「（还没有方案）」。

建议用法：平时用一套「标准」方案并设为默认；遇到特殊番剧，在设定画面里改好后「另存为方案…」另起一个名字，做完这部番再从「标点方案 ▸」切回「标准」。

{@Raw=文字} 里的文字默认原样显示；可在「中文显示为 ▸」勾选「{@Raw=…} 里的文字」，让中文行的 Raw 文字按所选方向转换。日文行的 Raw 文字从不转换。Raw 仍不参与标点和空格的字符／字体两层、隐藏句末「。」或两行合成一行的空格处理；里面不能含 }。导出去掉 {@Raw= 和 }，只留文字；发布时仍统一清理普通行首尾半角空格（即使原来包在 Raw 内），其余字形与句中空格继续保护。汉字读音与振假名照常。组编辑区和 F10 / F11 就地编辑把两端标记灰显，里面文字保持正常颜色。

组编辑区「ASS 标签」右侧「Raw」按钮：在输入框里先选中文字再点，选中的字直接放进 {@Raw=…}（例如选中「儲藏」变成 {@Raw=儲藏}），状态栏显示「已写入：…」，按 Enter 生效。没有选中时复制 {@Raw=文字}，状态栏显示「已复制：{@Raw=文字}」；不改文档、不提交输入、不移走输入焦点，复制后自行粘贴修改。悬停按钮时按 F1 打开本章。

处理顺序：中文简繁转换 → 标点和空格（字符标准化）→ 隐藏日文句末「。」 → 两行合成一行 → 显示字体。振假名、拼音、点选和 K 轴继续对应原字。设定画面、方案菜单与其中按钮的 F1 打开本章。

显示规则 → 两行合成一行（中间两个空格）：按原声／翻译分别勾选「对白」「歌词」「屏幕字等」，默认全部保持换行。对白包括顶部对白和同时说话；屏幕字等包括说明、制作名单和其他保留内容。只把硬换行 \N 显示为两个空格，软换行 \n 不动。工程记住设置，切换后立即刷新预览；原字幕、工作文档和编辑输入不变，不占撤销步骤。振假名、拼音、K 轴和点选继续对应原字。合成后的实测字宽超过本集画面宽减左右边距时，导出报告提示「{时间} 合成一行后太长，可能超出画面」，请检查画面或关掉相应开关。

显示规则 → 中文显示为：单选「原样（不转换）」（默认）、「简体」或「繁体」，按工程记住。只影响预览和导出，工程原文不变；按勾选的范围转换中文行，包括标为繁中的行里手打的简体字和简繁混写；日文正文和振假名、其他语言正文不变。预览、观剧、导出及审议包使用所选字种；编辑区和就地编辑框仍保留原文，按当前方向提示「显示为简体」或「显示为繁体」。

「中文显示为 ▸」单选项下面是按工程记住的「作用于」范围，各项无独立快捷键：

  • 「对白」「歌词」「屏幕字等」默认勾选，分别控制中文对白（含顶部、底部第二人）、歌词和屏幕字／注释类行。
  • 「旁注（中文行）」默认勾选，转换中文行的注释文字，与正文类别的开关独立；旁注目标仍按正文找，转换后跟随对应位置。
  • 「日文行上不含假名的旁注」默认不勾选；勾选后，仅转换没有平假名、片假名（包括半角片假名）的注释文字，含假名的旁注从不转换。

显示规则 → 繁体用字可选「台湾（默认）」「香港」「标准繁体」，两个方向共用；显示为简体时，地区表示原文按哪边的用语换回简体。「同时转换用语（例：软件↔軟體）」默认关闭，使用本机 OpenCC 词组表，不把字幕传到在线服务。例如繁体台湾用字把「这里是」显示为「這裡是」，简体并启用用语转换把「這裡是軟體」显示为「这里是软件」。人物有对应字种名字时 Name 栏优先使用，否则转换已有中文名；导出报告列出「中文显示为繁体：n 行（台湾用字）」或「中文显示为简体：n 行」。行数只统计正文或旁注文字实际发生转换的行，同一行只计一次。旧工程的繁体开关自动按「繁体」读取并保留地区和用语设置；选「原样（不转换）」即恢复原样，读音、拼音、旁注和 K 轴仍对应原字。

读音（振假名）

横排振假名尽量以所注汉字的实测字形中心为目标。宽度仍受本节的汉字／假名比例上限控制；只有相邻振假名需要避免互相重叠时，才在允许范围内左右避让并按需要压缩。旁边未注音的假名、汉字、标点或空格不再单独把注音推偏，例如「状況に」的「じょうきょう」会回到「状況」上方正中。人工缩放保留，纵向微调 Delta 只改上下位置；对白、歌词、模板预览及 F11／ASS 使用相同的横排规则。竖排沿用原有伸出与避让规则。

相连的不同词按现有拆词记录分别排版，例如「代表／取締役／社長」的三段振假名先在各自汉字上方居中、分别计算缩放，并保留更清楚的词间空隙。短读音有余量时可让相邻长读音少压缩；同一词内因送假名等原因产生的多段注音仍作为一个词处理。不会改写原文、读音或拆词记录，也不会自动再拆词。人工缩放及缩放下限优先，仍放不下时按原规则退避，检查报告提示「相邻词注音过密，已保留缩放下限并退避」。关闭比例限宽后仍保留词间碰撞处理。

半宽片假名和汉字组成的词会先对齐假名部分，再只给汉字注音，例如 ﾃﾛ行為（てろこうい） 显示为 テロ行為（こうい）；浊音、半浊音和长音同样适用。全宽转换只控制正文显示，不改变原文字符位置。旧工程中可明确识别的自动分配错误会在预览、导出和审议包中采用正确分配，编辑区原文、存储读音与人工设置保持不变。已确认／人工读音不自动重排；已有 K 轴的歌词保留原注音分配和拍，可按原流程刷新自动读音后复查 K 轴。

竖排行：字体以 @ 开头，且样式或整行标签旋转 90°／270° 时，振假名自动放在汉字右侧，使用相同字体的竖排字形（包括「ー」和小假名）。沿用本节的限宽、伸出、缩放下限和相邻避让规则，按旋转前的长度排版。靠近画面边缘时，正文和振假名整行内移；导出报告提示「竖排振假名靠近画面边缘，整行内移 {n} px」。工程里的原文、读音和位置设置不改，预览、点选与导出使用相同位置；无需新增快捷键。

竖排静态整行旋转支持点选；自动换行、局部混合旋转、动画中间状态和相邻独立列的避让仍需在真实画面检查。整行超过画面尺寸时，报告提示无法完全内移。

注音 → 振假名设置…：按「台词」「歌词」分别设置「限制振假名宽度」，默认都开启，限制为所注汉字排版占位宽度的 150%。占位宽度由 libass 按实际字体、字号、字距和横向缩放测量，包含字形两侧的留白，不按可见笔画的窄宽计算；例如同一等宽字体中的「自」和「私」使用相同的字格作为比例基准。百分比可选「100%（不超出汉字）」「120%（紧凑）」「150%（推荐）」「200%（宽松）」或「自定义…」（100–300%）。确定后预览重新排版，导出及跟随振假名的 K 轴特效同步生效；关闭限制取消宽度上限，相邻振假名仍会避让，人工设过缩放的注音保持原样。

振假名超过设定的宽度上限时横向压缩，最多压到工程的缩放下限（默认 60%）。先应用宽度限制，再处理相邻注音的碰撞；居中目标仍是所注汉字的字形中心，需要时会少量左右移动或继续压缩。例：底字占位 40 px，150% 上限允许振假名宽 60 px；自然宽度 58 px 的读音保持 100%，自然宽度 80 px 的读音压至约 75%。压到下限仍过宽时，检查报告提示「振假名太长，压到下限仍是汉字占位宽度的 {实际}%：{汉字}（{读音}）」。跨换行或超出测量画布而无法可靠测得占位宽度的范围，会在报告提示并沿用原笔画宽度限宽。在此对话框按 F1 打开本节；F11 和 ASS 导出使用同一套测量和排版。

旁注

组编辑区「ASS 标签」右侧有「旁注」「旁注（全部参数）」按钮。在翻译或原文输入框里先选中要注的字再点：直接在选中的字后面写好标记，例如选中「糧食庫」点「旁注」变成 糧食庫{@注:糧食庫=}就是怪物儲藏食物的地方吧，光标停在「=」后面，写好注释按 Enter 生效（Esc 放弃）；「旁注（全部参数）」同时填好位置 8、距离 0，以及这段字现在的字体、字号的一半和颜色，例如 {@注:糧食庫=;8;0;font=Source Han Serif Heavy;size=40;color=#FFFFFF}，按需要改。状态栏提示「已写入：{标记}」。没有选中（或选中的字里已有大括号标记）时，按钮复制下面对应的完整写法，状态栏提示「已复制：{写法}」，不改文档、不提交输入、不移走输入焦点，复制后自行粘贴填写。悬停按钮时按 F1 打开本章；「Raw」参见显示规则。

在组编辑区的翻译、原文输入框，或 F10 / F11 就地编辑框中直接写旁注标记，按 Enter 生效。标记以灰色原样显示，可以直接修改、删除，每次提交一步撤销。旁注不算正文，不影响读音、拼音、配对或 K 轴；注释文字按「中文显示为 ▸」的旁注范围转换简繁：中文行默认转换，日文行默认保留，只有启用「日文行上不含假名的旁注」且注释没有假名时才转换。旁注不转假名、不注音，目标和字体等参数不改。

{@注:被注的字=注释文字}
{@注:被注的字=注释文字;位置;距离;font=字体;size=字号;color=#RRGGBB}

和振假名的关系

日文行旁注放在上方（7 / 8 / 9）时，被注那段字不显示、也不导出振假名；已有读音仍保留。其他方位的振假名照常。原文旁注不会进入读音弹窗或假名转换。旁注不参与振假名碰撞排版，重叠时自行调距离。

预览、F10 / F11 和发布用 ASS 都显示旁注，每条旁注独立导出，时间、位置、移动、旋转和淡入淡出跟随所在行；私有标记本身不进入导出正文。歌词特效的逐字事件不带旁注，旁注静态跟随整行时间。F10 / F11 中点旁注不做任何事，不支持右键或拖动。

写错时

无效标记仍按原样保留，方便修改；这条旁注不显示。导出前检查和「检查」报告列出「旁注写法有误：{原标记}（{原因}）」。可能的原因：

  • 「找不到被注的字「{目标}」」
  • 「位置要写 1–9」
  • 「距离要是数字」
  • 「字号要是正数」
  • 「颜色要写成 #RRGGBB」
  • 「不认识的选项「{名}」」

普通文字里直接打的大括号 {…} 会按原样保存和导出；播放器会把它当成 ASS 标签，括号里的字不会显示，所以导出和检查报告会提醒。需要显示大括号时，手动改成全角 ｛｝，或写成 \{ \}（mpv 等 libass 播放器能显示）。旁注标记 {@注:…} 不受影响。

格式与 ASS 标签

正文与操作区下方的「格式」分区默认展开，点击标题可收起；字体、字号、粗斜体、颜色及清除格式的用法不变。「ASS 标签与旁注」默认收起，展开后可输入标签，或使用「旁注」「旁注（全部参数）」「Raw」按钮。两个分区分别记住展开状态；未选中字幕组时显示原因并收起。

快速颜色（按工程）

组编辑区右上角和 F10 / F11 就地编辑框格式行「颜色」按钮后面共用一排色块。有选中的字时只给选中的字上色，没选就是整行——与「颜色」按钮完全相同的规则、同样一步撤销（Ctrl+Z）。色块是与旁边按钮同高的正方形，带 1 px 灰边。

最后的「＋」打开选色窗口，默认当前字的颜色，选定后加到末尾。最多 12 个，满了「＋」灰掉并提示「最多 12 个」。色块右键：「改颜色…」「删除」「往左移」「往右移」。悬停提示如「#FFE36E：点一下给选中的字（没选就是整行）上色；右键改颜色或删除」。色块、右键菜单和选色窗口的 F1 打开本章。

颜色立即保存在工程设置 quick_colors（"#RRGGBB" 列表），换工程各用各的，不进全局设置；没有这一项时默认 #FFE36E（黄）、#8CD3FF（浅蓝）、#FF9CC2（粉）、#B8F28C（浅绿）。没有打开工程时色块不可用。

拆分、合并或移动分界时，选中字的格式跟着原字走；跨切点的格式段分成两段。拆分后的右半继承整行字体、字号、粗斜体、颜色、ASS 标签和位置。合并保留前一行的整行设置，后一行的文字格式只作用于它原来的字；位置或动画不同时保留前一行，状态栏提示「合并：第二行的位置／动画设置没有保留」。保存重开、撤销／重做都保留这些格式。

在字的上方或其他方位加注释文字，请看旁注。

组编辑区和就地编辑框上方的格式栏：

组编辑区「整行」字体框显示实际生效的字体：行首行内 \fn 优先，其次样式字体；你手动设置的字体优先于原字幕。没装的字体保留原名并加「（未安装）」，鼠标提示「本机没有这个字体，画面会用替代字体显示」。只有你自己选字体才修改这一行，不会自动换成别的字体。

  • 字体、字号（A− A+，Ctrl+Shift+< / Ctrl+Shift+>）、粗体 Ctrl+B、斜体 Ctrl+I、颜色、清除格式。选中几个字就只改这几个字，否则改整行；格式跟着字走。
  • ASS 标签栏：范围可选“自动范围”“整行”“整组”。自动范围按选区应用；全选文字视作整行。整组同时应用当前组的原声和翻译，振假名跟随各自正文；保留各行其他手动标签，只替换同类标签，一步 Ctrl+Z 撤销。该范围只控制 ASS 标签，字体／颜色按钮和“清除格式”沿用当前行或选区的规则。清空标签并回车会恢复这个范围内各行原字幕的标签。
  • 整行或选中的字可写 ASS 覆盖标签——旋转 \frz \frx \fry、斜切 \fax \fay、缩放 \fscx \fscy、\fsp \bord \shad \blur、颜色和透明度、\t(…) 动画、\org \clip \fad \fade（后四个只能整行；局部选区请改选“整行”或“整组”）。 输入时检查：不认识的标签、\pos \move \an（请拖动或用位置栏）、\k（用 K 轴工具）、\p 不收，并说明原因。
  • 振假名跟着旋转、斜切、缩放、移动、颜色和淡入淡出一起变。原字幕不变。

对白自动跟随淡入淡出：日文原声没有自己的 \fad／\fade 时，自动跟同组翻译的淡入淡出，振假名也跟随。翻译必须给出唯一一致且有效的淡入淡出，输出起止时间必须相同；翻译有冲突、缺标签或时间不同时不会自动套用。日文格式栏显示“自动跟随同组翻译”，自己写的淡入淡出优先；\fad(0,0) 可明确关闭跟随。现有工程无需重新合并，预览、F10／F11、发布 ASS 和整季导出共用此规则；只派生显示结果，原字幕、原文及来源记录不改。此规则只针对对白，歌曲仍沿用歌词淡入淡出设置。

位置

组编辑区的「位置」分区在「ASS 标签与旁注」下方，默认收起；点击标题展开九宫格、X / Y、作用范围与位置按钮。展开状态保存在本机；暂时不适用时显示原因并收起，恢复适用后还原上次选择。

X / Y 以这一集的字幕坐标保存。打开旧集或更换视频后需要换算时，先在集目录 journal/backups 保留文档备份，再一次性换算手动位置、移动、旋转中心和裁剪的横坐标，保留画面上的位置；原字幕自带的位置仍从来源坐标换算。

  • 组编辑区的“位置”栏：九宫格对齐点（换对齐点时单行字不动）、X / Y（精确到 0.1 像素，回车或离开输入框生效）、整组 / 只这一行、恢复原位置、左侧说话人 / 右侧说话人、移到顶部 / 移到底部 / 底部第二人（换成模板对应的样式）。
  • 底部第二人：换成模板的第二人样式 CN.Alt / JP.Alt，在底部居中、普通底部字幕的上方，两人同时说话时让第二个人的台词不压住第一个人。高度由样式模板里这两个样式的底边距决定：第二人整对字要高过普通底部那一对（含振假名），字号调大后请一起调高（例如普通 76 / 10 时约 223 / 157）。模板里没有这两个样式时会提示先在「样式模板」里加上。
  • 同一组的翻译和原文在导出时分在两层（翻译在上一层），所以从屏幕字转成普通台词后再移到顶部，中文仍在日文上方，不会被 libass 的自动避让挤乱。

自动 K 轴（按歌声）

K 工具条「提示 → 自动 K 轴 ▾」先把人声从伴奏里分离出来，再用两个识别模型按每一拍的读音（假名）对齐整首歌，最后按人声的停顿定出空拍和结尾。不管选哪种范围，都会对整首歌一起对齐（上下文最完整），只把结果写进要求的句子。

  • 这一句：结果画成青色虚线建议，Enter 或「采用建议」写入，Esc 隐藏。
  • 选中的句：列表里选中的歌曲（至少两句）。整首歌：当前组所在的整首（同类别、间隔不超过 15 秒）。直接写入，一步撤销「自动 K 轴」，然后打开结果窗口。
  • 写入的拍标为「建议」，仍需试听、确认；问题列表显示「自动建议还没确认」。

歌词行的开始／结束不必很准：可以把句子时间放宽，程序会自己找每一拍，句首到第一拍之间、最后一拍之后自动是空拍。结果落在句子时间外时，这一句（原声、翻译两行）的时间会放宽到包含所有拍（只放宽不缩短），但不会与原来不重叠的相邻可见对白／歌曲组新增重叠。越界的拍会截短到边界，截短后不足 100 毫秒标需复查；原有重叠保持。被挤到边界上的拍不会变成 0 长度：先用它和下一拍之间的空拍，不够时由下一拍让出，尽量各留 100 毫秒。

选项（记在工程里）

  • 同时重新分配翻译拍（默认勾）：按短语重新分配翻译拍，只改没自己改过的翻译行（拖过、打过的保留）。
  • 最后一拍：「唱完就结束（推荐）」= 人声停下的地方；「延长到这一句结束」= 到句尾。
  • 拍头提前量：每个人放拍头的习惯不同（有人放在辅音开始处，有人放在元音处，实测相差 20–50 毫秒）。「按我调过的拍（推荐）」用这首歌里你打过、拖过的原声拍（至少 20 拍）算出差值并记住，下次没有手调拍时沿用；「不调整」；「自定义…」（−150…+150 毫秒）。状态栏和结果窗口写明这次用了多少。
  • 长音拍 ▸（在「拍头提前量 ▸」之后）：单选「平分（推荐）」／「按我调过的比例」。平分把同一长音分成等长的两拍，让 \kf 扫过「こ」「う」的速度一样，看起来像一个音一直扫过去；习惯模式取这首歌手打或拖过的长音拍的中位比例（至少 5 个，限制在 30%–80%），学到后存成工程的「我的长音习惯」。不到 5 个用工程存过的比例，都没有则平分。
  • 翻译跟整个长音走（推荐）（「长音拍 ▸」分隔线下面，默认勾）：前一拍与紧跟的长音拍合为一个音，音拍数和时长相加，翻译按整个音分配，例如「前」对应「こう」整个长音。汉字读音的第一拍和空格、标点、换气后的第一拍不算长音，例如「ない　今」的两个「い」是两个词，不会合成一个音，句子中间的空格分段也不会被跨过。只有翻译字比原声音多时才按时间在音中间切分，恰好落在拍界时仍链接到原声拍。不勾则长音拍单独参与分配。此设置同时用于「同时重新分配翻译拍」、「更多 ▾ → 歌词 → 重新分配翻译拍 ▸」和「歌词对应」的自动建议／「自动对应」。
  • 覆盖手调过的句（默认不勾）：不勾时，已确认或有打过、拖过、手改过的拍的句子不覆盖，但它们现有的拍头会作为参照帮助邻句。
  • 按起音（旧方法，只这一句）：原来的起音建议，保留。

进度、取消和结果

处理在单独的进程里进行，窗口照常响应。进度依次显示「读取音频」「分离人声」「识别（1/2）」「识别（2/2）」「对齐」；第一次使用时多一步「下载模型（约 2.5 GB，只需一次）」。「取消」、换集或关闭工程会结束处理，什么都不改。处理期间改过文字、读音或拆合的句子不写入（结果写明「处理期间改过」），请重新运行。

结果窗口列出每一句：更新，或跳过的原因（已确认或手调过／处理期间改过），以及需要复查的拍数；双击跳到那一句，窗口不关。放宽时遇到邻句会另列「{n} 句放宽时碰到相邻的句，拍已截短（橙色框）」。状态栏和结果窗口在「拍头提前量」后显示「；长音：平分」、「；长音：按我调过的拍 62%（8 个）」、「；长音：工程存过的 62%」或「；长音：手调不到 5 个，平分」；百分比与个数按这次结果显示，没有长音拍时省略。

需复查：两个模型结果相差较大，或者这一拍没有读音（汉字没有振假名）时，拍画成橙色框，K 条提示「橙色框 = 两种识别结果不一致，请试听」。拖动这一拍、重新打或确认 K 轴后橙色框消失。

自动 K 轴会降低静音帧里非空白记号的概率；单独的长音拍（如「こ｜う」「せ｜い」和单独一拍的「ー」）与前一拍一起对齐，再切分同一段人声，避免在长音中间留下空拍。出现持续至少 100 毫秒的明确元音变化时按变化切分，否则默认平分同一段人声。两拍放不下各 100 毫秒时平分并标需复查。拍头提前量同时作用于两拍；拍内已有长音符号（如「ろー」）仍是一拍。

自动 K 轴最多做 3 轮精修：两个模型相差不超过 60 毫秒、长度合适且拍头后 100 毫秒内有人声的拍作为固定锚点，只重对齐其间不可信的拍。融合在跨度允许时保证相邻拍至少 100 毫秒；放不下时按音拍数和时长分配，并标需复查。句尾不超过下一句的第一拍；原来不重叠的句子也不越过下一句的开始。上一句的长音一直唱到换气、这一句第一拍却落在换气之前时（例如「…知るんだ」后接「明日（あす）」，あ 和拖长的 だ 同是 a 音），第一拍改从换气后人声重新出现处开始；整首第一句、或句首前已经换过气时不改。

新增复查来源：仍不足 100 毫秒的拍（只有「っ」和句尾拍除外）、拍头后 100 毫秒都没有人声的拍，以及跨度不足而按比例分配的拍。辅音起头的一格较弱，后面能听到人声时不会仅因此标为静音起拍。

准确度和速度

实测（拍头误差 = 自动结果 − 手调）：剑姬神圣谭 ED（用户手调）中位数 30 毫秒，83% 在 100 毫秒以内，93% 在 200 毫秒以内；原来的起音建议是 240 毫秒、33%、40%。少女革命 OP／ED（去掉拍头习惯差后）中位数 28／21 毫秒，80%／95% 在 100 毫秒以内。比对时发现手调参照里也有不准的地方（句首拍拖到字幕开始、ん 放在长元音中间等），自动结果在这些地方往往更接近声音。

不准的情况：重混响或和声很重的段落、最后的长音、汉字没有读音、字幕歌词和实际唱的不一样。这些地方常带橙色框，请试听。

CPU 上一首 90 秒的歌第一次约 2 分钟；结果缓存在工程 cache/kalign，同一首歌再次运行（例如只改了几个字）只要几秒。电脑上 PyTorch 能用 CUDA 时自动使用显卡。

左键 = 选中 / 跳转：点歌曲组的色条（上方翻译、下方原声）选中那一组；点在拍上选中这一组并把播放头移到这一拍开头；点空白处只移动播放头。右键 = 播放这一拍：在假名行、频谱／波形区的拍上播原声这一拍；在翻译行的拍上播翻译这一拍；拍以外的地方右键不做事。灰色提示为「左键=选中/跳转 右键=播放这一拍 拖边界=调拍 Alt=不吸附」。

拍文字（假名、原声和翻译）有约 90% 不透明的深色底块、四周 3 像素留白，白色粗体文字带 2 像素深色描边；K 条上下两行的频谱压暗约 40%，频谱明亮处也能辨认；拍边界有深色衬线。拖拍边界仍调拍并遵守吸附；按住 K 跟唱、空拍、自动 K 轴照旧。工具条的「速度（歌曲）」调整并记住歌曲速度，离开并选中对白时自动用独立的对白速度。卡拉 OK 模式开关的 F1 打开本节。

打拍时可用 Ctrl+滚轮放大到约 1 秒查看连续波形与更细的起音频谱；选组保持缩放。精细图在后台计算，完成前显示原图，详见打轴（波形）。快捷键不变。

边听边打

  • 选中歌曲组，按 K：从行首前开始播放；每一拍唱的时候按住 K（按下 = 开始，松开 = 结束）。Esc 放弃。
  • 刷剧连打：播放中直接按住 K 跟唱，歌曲组优先打原声的假名拍；没有原声时打翻译。应用歌词对应后，翻译会跟着原声拍走。
  • 从这一拍重打：在 K 条上点一拍，再按 K，前面的拍不变。
  • 慢速 0.5× / 0.75×，音高不变，时间按原速记录。

英文按音节拆拍

K 轴工具条点「更多 ▾ → 歌词 → 英文按音节拆开」，把当前歌曲组原声、翻译里能拆的英文词拆成音节拍，两行都有英文就两行一起拆，一步撤销「英文按音节拆开」。没有可拆词时灰掉并显示「（这一行没有能拆的英文词）」。单音节词如 truth、take、long、time、Let's 保持一拍。

本机装了 Pyphen（en_US 断字词典）时参考它的拆分位置；它是给排版断行用的，像 away、over、alone 这类词不拆，所以它拆出的段数比元音规则少时改用元音规则（a-way、o-ver、a-lone）。没装 Pyphen 时只按元音组、词尾和辅音规则拆分。规则和词典都只是起点，例如 revolution 可拆成 re|vo|lu|tion（词典可能不同），请按唱法检查，拆得不对用 Ctrl+点字间／拍界拆开或合并。

已打拍按拆出音节的字母数分配原时间，拆出的拍标为占位／未完成，需要重打或拖动；其他拍、文字和特效保留。歌词对应的起点留在第一片、终点留在最后一片，拆原声后翻译仍跟着原声走。按钮上按 F1 打开本节。

歌词对应的写法与应用

K 轴工具条点「更多 ▾ → 歌词 → 对应…」打开「歌词对应」。当前组须为歌曲且原声、翻译都有文字；灰掉时菜单项写明「（不是歌曲）」「（这一组没有原声（日语））」或缺翻译的原因。表格覆盖同类别、相邻间隔不超过 15 秒的整首歌，当前组选中。

列为「时间」「原声（日语）拍」（拍间用 | 隔开）「对应（可以直接改）」「状态」。写法例如 在（ひ）陽（か）光（り）映照的（さす）校（ガー）庭（デン）：括号全角、半角都可以，括号里的假名必须依次包含整拍，覆盖全部原声拍；括号外必须与翻译一致，空格、标点附在前一段。

已有对应直接显示；没有对应时是灰色自动建议，修改或点「采用」变黑。「自动对应」只改选中行，先按停顿、标点和空格匹配短语，再按音拍数与时长分配，参考共同汉字；英文按词，每段至少一拍，译文单位较多时合并相邻文字（表格不拆原声拍）；一个英文词可以对应多拍，一拍也可以对应几个词。自动建议只是起点，需要检查。「试听这一行」播放选中行，「帮助」或 F1 打开本节。

状态「✓」表示对上；否则显示红色原因：假名拍不符、翻译多字或少字、括号不成对、有段没对应拍。灰色的自动建议显示「✓ 建议，没采用（应用时不改）」。「自动对应」会填入建议并直接采用（所以之后「采用」是灰的）。「应用」一次应用所有黑色、对上且有改动的行，一步撤销「歌词对应」；灰色建议和没改动的行保持原来的轴（原来的轴可能比这里的写法更细，例如一个长音中间切开）。有错误行时询问「{n} 行还没对上，这些行不改。继续吗？」。「取消」保留原有轴。

应用会替换翻译原来打过、拖过或吸附过的拍，按对应段合并，每段开始跟随第一原声拍的开始、结束跟随最后拍的结束；以后重打或拖动原声拍，翻译一起动，日文汉字块仍按假名拍合计。

重新分配翻译拍

「更多 ▾ → 歌词 → 重新分配翻译拍 ▸」「这一句」「选中的句」（列表选中至少两句歌曲）「整首歌」：按原声现在的拍重新分配翻译拍，一步撤销「重新分配翻译拍」，会覆盖所选句里自己改过的翻译拍。规则：

  1. 先分短语：原声在空格、标点处，或两个词之间停顿至少 0.15 秒处断开（一个词里面的换气不算，例如「窓」的 ま｜ど 之间）；翻译在空格和标点处断开。再一段对一段，例如「我知道...我都知道啦...」对「分かってる…　分かってる…」时，「我知道」对第一个「わかってる」，「我都知道啦」对第二个。
  2. 短语里面，每个翻译字（英文按词）对一段连续的原声拍，按音拍数和时长尽量平均；两边都有的汉字（明天／明日、今天／今日、雨）在两边句中位置相近时尽量对到一起，位置差很远时（「產生」和「を生め」、「輝映」和「照らし合い輝いて」）不算，免得中间的字挤成一段；翻译字比拍多时，把最长的拍拆成两三份（例如「啦」在最后长音 る 的后半）。
  3. 落在原声拍边界上的边跟着原声拍走；拆开一拍产生的中间边按比例跟着移动。

「自动 K 轴」勾了「同时重新分配翻译拍」时也用这套规则，但只改没自己改过的翻译行。「歌词对应」表格里的自动建议同样先分短语，不拆拍（翻译字比拍多时合并相邻的字）。意思上的对应（如「體貼」对「やさしさ」）不会自动判断，需要时在表格里改。

翻译时间对齐原声

「更多 ▾ → 歌词 → 翻译时间对齐原声 ▸」「这一句」「选中的句」「整首歌」：歌词组里的翻译用原声的开始和结束时间，两行同时出现、同时淡出；只有组里的拍超出原声时间时才放宽到包住所有拍（原声也一起放宽）。一步撤销「翻译时间对齐原声」，已经一致时状态栏写「这些歌词的翻译和原声时间已经一致」。字幕组原字幕里翻译和原声的结束时间常常不同（例如翻译早 0.27 秒结束），淡出就会一前一后。「自动 K 轴」写回时需要放宽句子时间的组，原声和翻译放宽到同一个开始和结束时间。

淡入淡出

「更多 ▾ → 歌词 → 淡入淡出 ▸」「这一句…」「选中的句…」「整首歌…」：打开「淡入淡出」窗口，显示现在多数歌词行的淡入淡出（原字幕的或改过的），设好「淡入」「淡出」（毫秒，0 = 不淡入／不淡出）后「应用」，原声和翻译一起改，一步撤销「淡入淡出」。设置写成这一行的 ASS 标签 \fad(淡入,淡出)，替换原字幕里的 \fad／\fade，原字幕本身不变，振假名和旁注跟着这一行淡入淡出；「恢复原字幕的淡入淡出」去掉这个设置。窗口里按 F1 打开本节。

预览和导出会避免歌词碰撞：使用模板位置的翻译与原文同层时，翻译放到上一层，字体变高也不会互相挤开；已有不同层或单独定位的行保持原样。同语言、同样式、都没有自己的 \pos／\move 的相邻歌词，重叠不超过 1 秒且不到较短一句的一半时，前句及其振假名／旁注在后句开始处结束。只改导出事件，工程里的时间不变。正文和振假名一拍中途的字体等标签不会打断 K 轴变色。

在波形上修

「波形」「频谱」同样适用于打拍；K 工具条保留「打拍」「提示」「空拍」三组，歌词操作在「更多 ▾ → 歌词」，效果与参数在「更多 ▾ → 特效」，窄时自动换行。「显示提示线」持续显示青色起音虚线与可靠的浅灰收音虚线；「吸附到提示线」让拍边吸附到 6 像素内的起音／收音，与画面切换、相邻行、原声拍边界取最近目标，Alt 临时不吸附。选组保持缩放，「适合本组」可查看整组。

起音线只保留局部明显的起音：相邻至少 100 毫秒，靠得太近时保留较强的（一样强时保留较早的）；按附近一秒内的平均与最强起音强度过滤弱峰，安静段落使用自己的局部门槛。显示、吸附和「起音建议」共用这套结果，歌曲拍点仍需试听确认。

收音规则：起音后至少 60 毫秒声音，峰值振幅至少 0.02（满幅为 1）；随后振幅低于段内峰值的 25%，在下一起音之前持续至少 120 毫秒，才标记变弱处。短暂变弱不标记；「起音建议」会用可靠收音点建议拍的结束，在下一起音前留出至少 120 毫秒的空拍，采用前不改已存拍。

音频尚在读取时可关闭程序或切换集，旧集的读取任务会停止；下次打开时重新读取，不使用未完成的缓存。关闭样式模板窗口也会停止后台预览。

  • Ctrl+点两个字之间 = 拆开一拍；Ctrl+点拍的边界 = 合并。拆合保存在工程里。

空拍

相邻拍之间的空隙是空拍，K 条画成斜线格子。点格子选中空拍；拖前面的边只改上一拍的结束，拖后面的边只改下一拍的开始，两端不会一起移动，也不会越过另一端。没有空拍时仍用共用拍界。

选中一拍后点「后面加空拍」或 Shift+K，把结尾提前 0.20 秒；拍长不足 0.40 秒时留出它的三分之一，下一拍开始不变。需要有下一拍，行尾拍不提供此操作。点格子选中后点「删掉空拍」或 Delete，上一拍延到下一拍开始。每次加、删、拖都是一步撤销。

按住 K 跟唱时，松开到下次按下超过 0.15 秒会保存为空拍，0.15 秒以内连唱。「起音建议」的青色实线同时显示建议开始与结束，可靠收音后到下一起音前安静至少 0.12 秒时会建议空拍。空拍不算没打完；译文链接到原声结束点时跟着该结束点，开始点分别跟随。导出为空的 {\kf…}，旧 K 轴格式里的空标签导入后同样显示为空拍。

很窄的空拍也能点格子选中，两端仍可拖动；无空拍的导出保持原样。振假名按各拍和空拍输出，同一日文汉字块仍按假名拍的总时间输出。

卡拉 OK 特效与预设

占位拍、起音建议和没打完的行都会显示并导出所选特效，无需先打完拍。勾选“翻译行跟着”时，翻译行没有自己的 K 轴也会用自己的占位拍跟着原声特效；占位拍仍不算完成。

多句一起套特效：列表里选中两句以上歌曲时，「更多 ▾ → 特效」选效果或预设会套到选中的所有句（原声和翻译两行），状态栏「已把特效「{名称}」套到选中的 {n} 句（Ctrl+Z 撤销）」；只选一句时只改这一句。也可以在列表里右键「K 轴特效 ▸」，选择全部现有特效（包括惊恐颤抖）或已存的预设。「参数…」窗口的「应用到：这一行／选中的组／整首歌」不变。

同一个字唱到后，拍与拍之间保持已唱颜色；缩放回落和下一拍衔接不会闪回未唱颜色。擦除会沿着该字的各拍连续推进。

K 工具栏的「更多 ▾ → 特效」选择效果，「更多 ▾ → 特效 → 参数…」打开“卡拉 OK 特效参数”浮动面板。拖滑块或改数值、颜色、开关，编辑预览与 F10/F11 画面同步更新；预览和导出使用同一套生成方式。面板可保持打开，换特效与参数不会改拍。

  • “应用到：”选“这一行 / 选中的组 / 整首歌”，改参数立即应用，也可点“应用”。这一行优先采用选中拍的行，否则采用「设置 ▾ → 打轴对象」的行（整组时为原声行）；整首歌与双行 KTV 按同一类别 OP/ED/IN 的相邻歌词间隔不超过 15 秒判断，夹在中间的制作人员等非歌曲组不会打断。包含对应光晕副本，一次应用一步撤销。没有打完的行保留为占位拍。
  • “存为预设…”保存到当前工程，以后可在“特效”下拉直接选；面板下方选择预设后可“重命名预设…”或“删除预设”。删除预设不影响已应用的行。重复段落库记下并套用完整特效与参数。

记下来

  1. 在做好的那一集里，列表中选中这一段的几组（OP 的全部歌词、开头旁白……）。
  2. 工具 → 重复段落 → 记为重复段落…（或列表右键）。填名称、类别（片头曲 / 片尾曲 / 插曲 / 旁白·固定台词）、版本（例如 TV 版）。

在别的集套用

  1. 打开另一集，音频读完后会在空闲时询问「这一集可以自动处理」，列出「找到重复段落：片头曲《…》……」。点「套用重复段落…」打开对照表；若也有时间偏差，可以先自动调轴，再套用段落。
  2. 工具 → 重复段落 → 查找并套用…：左边是库里每一段找到的位置和相关度（只放了一部分会写明）；右边是每一行要做的事，逐项勾选。
  3. 可以“试听”跳到找到的位置；头尾对不上时可以勾“按比例缩放时间”（默认只平移）。
  4. “应用所选”：一步完成，Ctrl+Z 整体撤销。没套用的项会逐条说明原因（同一行同一原因只列一次）。
  5. 库里同一组的原声和翻译会一起对到这一集的同一组：字幕组的原声＋翻译那一组，优先于别处文字相同的日文 CC 字幕行，CC 行保持原样。

询问与自动调轴合并，同一集在这次打开期间只问一次，可选「先不处理」或勾选「这一集不再询问」；详见自动调轴。这是 AUTOTIME.md §7.5 的新行为，取代 PASSAGES.md §5.1 的状态栏提示。

粘贴歌词块

「歌词文件」旁点「粘贴歌词块…」，在大文本框粘贴，再按「读入」。一句一块、空行分块；每行名称和内容用全角或半角冒号分隔。没有的字段可省略，以 # 开头的说明忽略。

# 歌名：輪舞-revolution
# 类别：片头曲
时间：0:00:25.84 - 0:00:30.01
原文：光差す校庭 手をとり合い
读音：光（ひかり） 差す（さす） 校庭（ガーデン） 手（て） 合い（あい）
假名拍：{\kf16}ひ{\kf25}か{\kf22}り{\kf37}さ{\kf23}す{\kf37}ガー{\kf80}デン{\kf24}て{\kf22}を{\kf24}と{\kf23}り{\kf35}あ{\kf49}い
翻译：在陽光映照的校庭  握著彼此的雙手
对应：在（ひ）陽（か）光（り）映照的（さす）校（ガー）庭（デン）握（て）著（を）彼（と）此（り）的（あ）雙手（い）
- 「# 歌名：」「# 类别：」写在第一块前面，对后面所有块有效，直到出现新的「# 歌名：」（一个文件可以放几首歌）。类别写「片头曲」「片尾曲」「插曲」。
- 「时间」：这一句在集里的开始和结束（和 Aegisub 一样的写法）。「假名拍」里的 `{\kf数字}` 是从这一句开始算的百分之一秒；没有字的 `{\kf数字}` 是停顿。
- 「读音」：只写有汉字的词，「词（读音）」，送假名包含在词里（「合い（あい）」），读音用平假名；歌里的特殊读法照写（「校庭（ガーデン）」）。
- 「对应」：写法同 2.2。只有翻译（例如英文歌词）的句子可以只写「时间」「翻译」，翻译里可以带 `{\kf数字}`（英文按词或音节）。
- 格式错误：「第 {n} 块没有“时间”」「第 {n} 块的时间写法不对：{内容}」「第 {n} 块“读音”里的「{词}」在原文里找不到」「第 {n} 块“假名拍”的假名和原文的读音对不上」，以及 2.3 的对应错误。
- 以前的一行写法（「K轴」注释行 `{\kf…}…\N{KaraOKMapping:…}{CNOrigin:…,JPOrigin:…,KanaOrigin:…}`）照样认得，不用改。

对应错误会说明：括号里的假名和原声拍对不上：第 {n} 拍应该是「{假名}」；翻译文字对不上：多了「{字}」/ 少了「{字}」；括号不成对；有一段没有对应任何拍。错误块不导入，其他有效块可以继续。

让语言模型帮忙整理

点「复制提示词」复制以下全文，在末尾填入日文歌词、中文歌词和假名 ASS 时间轴，交给 Claude（例如 Sonnet）或其他语言模型。把返回的歌词块粘贴回来，程序逐块校验；模型写错的块会列出原因。

请帮我把一首日语歌整理成“歌词块”。我会给你三份资料：
1. 日文歌词，每行一句；
2. 中文歌词，每行一句，和日文一一对应；
3. 用 Aegisub 打好的卡拉 OK 时间轴，只有假名，每行一句，是 ASS 字幕行（Dialogue 或 Comment 行，里面是 {\kf数字}假名）。

每一句输出一个歌词块，块与块之间空一行，格式：
时间：开始 - 结束        （照抄第 3 份资料里这一行的开始和结束时间）
原文：日文歌词
读音：词（读音） 词（读音）……   （只写有汉字的词，送假名写在词里，读音用平假名；特殊读法按假名时间轴里实际唱的写）
假名拍：{\kf数字}假名{\kf数字}假名……   （照抄第 3 份资料，不要改任何数字和假名）
翻译：中文歌词            （照抄，不要改字）
对应：中文一段（这一段唱的假名）中文一段（假名）……

“对应”的规则：
- 把中文按意思切成几段，每段后面的括号里写它对应的假名，必须是假名拍里连续的几拍，按顺序把这一句的假名全部用完；
- 所有括号里的假名连起来，要和这一句假名拍里的假名完全一样（停顿不算）；
- 中文不能改字、不能漏字；空格和标点跟在前一段后面；
- 尽量让意思对得上：日文唱到“光”的时候，中文也在唱“陽光”。
只有中文、没有日文的句子（例如英文歌词）只写“时间”和“翻译”。
不确定的地方在那一块最后加一行“备注：……”。只输出歌词块，不要别的说明。

第 1 份（日文歌词）：
……
第 2 份（中文歌词）：
……
第 3 份（假名时间轴）：
……

导出与检查

发布 ASS 自动清理：单集和整季都会在排版与特效生成完成后，去掉每行首尾普通半角空格（U+0020），跳过无正文的空白 Dialogue（包括只剩格式标签的行）。不改工程原文、预览或工作格式；保留句中空格、硬换行及中间空白行、全角空格、\h 显式硬空格、绘图与原 Comment 注释。报告列出清理的空格与空白事件数量。

注音行顺序：单集／整季导出窗口可选「统一放在文件末尾」（默认）或「紧跟对应正文行」。对白、歌词的 Ruby／Furigana／拼音均适用，不改变注音的画面坐标、样式、时间或特效参数。逐字特效把一句拆成多条正文事件时，注音跟在该句的正文特效块后；同一正文的多条注音维持原相对顺序。按工程记录的所属正文关联，不靠样式名猜测。若重排会改变已定位特效的叠画关系，输出副本会派生图层编号以保留原绘制次序，报告列出数量；工程图层不改。

此选项只用于本次发布，默认每次打开仍为文件末尾；不会保存到工程或改变预览。简繁两份和整季各集使用同一次选择；取消不写输出。原配简繁报告记录清理后的最终文字。F1／帮助按钮打开本章，无独立快捷键。

发布导出在后台生成并检查字体，显示「正在导出…」和「取消」。处理期间不能编辑当前窗口；按「取消」或 Esc 停止测量，不写导出文件或报告，状态栏显示「已取消导出」。没打完的 K 轴仍在开始处理前询问；字体问题在处理结束后询问。关闭主窗口会先取消并等待任务结束。进度窗口的 F1 打开本节。

正文的行内 \r样式名 重置引用的样式会一并保留；来源样式重命名时，引用同步对应到输出样式，预览与发布导出一致。

「名字栏（Name）」可选常用称呼、全名、只写姓、只写名或原标签；见人物与说话人。

  • 文件 → 导出 → 发布用 ASS…：按工程设置生成正文与注音，完成发布清理并按所选顺序排列注音；保留 ASS 标签和正文里的 @ / #，不覆盖原字幕。同时写一份导出报告。
  • 导出前检查：顺序、原文去向、没打完的 K 轴、字体；有问题会问你是否仍然导出，问题写进报告。
  • 没有显示时间的行（结束不晚于开始、整行在片头之前）写成注释行，报告列出；列表里显示“不显示”标签。
  • 普通台词不导出 K 轴，也不写出原字幕自带的 \k。

有中文行时，可勾选「同时导出简体和繁体两份」（与整季导出共用本机记忆）。所选路径 第05集.zh-Hant.ass 会生成 第05集.zh-Hans.ass 和 第05集.zh-Hant.ass；没有语言后缀时在 .ass 前加。每份各写一份 .export-report.txt，同名文件分别询问覆盖或另存带编号的文件。两份只改变中文转换方向，工程的作用范围、地区用字、用语转换、Name、Blur 和注释行设置都沿用；日文正文和振假名不变，日文行旁注仍遵守工程范围与假名保护。不勾选时仍按当前「中文显示为」设置导出一份。取消生成或字体确认时，两份和报告都不写。

导出整季

文件 → 导出 → 整季发布用 ASS…：把工程里每一集一次导出到同一个文件夹。

  1. 「输出文件夹」默认是视频所在的文件夹（播放器打开视频会自动加载同名字幕），可点「选择…」换；「语言后缀」可选或直接输入，例如 zh-Hant。两项按工程记住。
  2. 文件名 = 视频文件名（去掉 .mkv）+ .语言后缀 + .ass，例如 S01E005 - Sword Oratoria - 05.zh-Hant.ass；没有视频的集用集名。表格逐集列出输出文件和状态：「将导出」「已存在（导出时询问）」「没有视频，用集名」「还没有合并，跳过」。两集输出同名、后缀里有 / \ : * ? " < > | 或空格、文件夹不存在时，「导出」不可用并在下方写明原因。和这一集原字幕是同一个文件的不导出（不覆盖原字幕）。
  3. 点「导出」：输出文件夹里已有同名文件时先列出来，选「覆盖」「跳过这些集」或「取消」。
  4. 后台逐集生成并检查字体，进度窗口显示「第 i/n 集 S01E005：正在生成…／正在检查字体…」，可「取消」；取消后一个文件也不写，状态栏显示「已取消整季导出，没有写入文件」。正在编辑的这一集按窗口里现在的内容导出（包括还没保存的改动），其他集按已保存的内容。
  5. 结束后显示「整季导出报告」：导出了几集、跳过和失败的集及原因、每集的事件数、没打完的 K 轴、字体问题等，同时写成 工程文件夹名.语言后缀.export-report.txt 放在输出文件夹；「打开输出文件夹」打开资源管理器。一集出错不影响其他集。整季导出不逐集询问，问题都写进报告。

整季也可勾选「同时导出简体和繁体两份」：「语言后缀」换成「简体后缀」（默认 zh-Hans）和「繁体后缀」（默认 zh-Hant）。表格每集列出两个文件，两个后缀不能相同（忽略大小写和首尾点、空格）；重名、已有文件和原字幕保护分别检查。已有文件询问会同时列出两种文件，可「覆盖」「跳过这些文件」或「取消」。后台完成全部生成和字体检查后才写盘，取消不写任何文件；整季报告每个文件一节，文件名为 工程文件夹名.简体后缀+繁体后缀.export-report.txt。两份只覆盖方向，工程转换范围与用字、用语设置保持不变。

同时导出审议包：勾选「同时导出审议包（发布前给大模型复查）」，本次实际导出 ASS 的每一集会在同一个输出文件夹另存一份 Markdown + JSONL。默认不勾选，选择记在本机。文件名为 集名.review-年月日-时分秒.md 和 .jsonl；同名已存在时自动加序号另存，不覆盖以前的包。被跳过或 ASS 全部导出失败的集不生成包。

每集只出一份审议包，简繁两份 ASS 共用它。包沿用「工具 → 审议 → 导出审议包」的工程当前显示规则、语言、拼音和人物表，内容与 ASS 采用同一份文档（含当前集未保存的改动），不按 ASS 的简繁双份覆盖改写包里的字种，便于按现有流程导回审议意见。生成包也在后台进行，进度显示「正在生成审议包…」，此时取消仍不写任何输出文件；审议包失败会在整季报告中单独列明，已成功的 ASS 继续导出。

参考原配简繁字幕与对照报告

单集和整季发布导出均可勾选「参考原配简繁字幕，附对照报告」，每次打开默认关闭。单集可选另一字形的原配 ASS／SRT 文件，整季可选包含各集原配字幕的文件夹；留空仅查找导入原字幕所在目录，不搜索相邻目录和子文件夹。原配放在其他位置时请指定路径。同集有多个无法区分的版本时不会随意选择。

输出方向沿用现有规则：勾选「同时导出简体和繁体两份」时分别处理两种字形；只出一份时沿用工程「中文显示为」设置。语言后缀只决定文件名；当前设为「原样（不转换）」或不在中文转换作用范围的类别仍保持原样，报告会说明。

程序按原始事件、正文和来源顺序对应原配字幕，调过的当前时间不影响配对。正文没有变化时优先复用可靠对应的原配另一字形；当前工程的时间轴、样式、位置和特效保持有效。正文有局部修改且能安全定位时，未改部分保留原配用字，只转换修改部分。拆并句、重复歧义、特效／Raw 边界、已有逐字注音或 K 轴对应无法保持时，自动回退到当前正文的正常简繁转换，不要求逐句确认。

若字幕在导入工程前就改过译文，请把真正原版的同字形底稿与原配另一字形放在所选参考文件夹（单集为所选文件的目录）中，保留集号与字形标记，例如 01.cht.ass 和 01.chs.ass。找不到底稿且原配译文与导入原文不同，程序无法证明哪些是导入前的改译，会保留当前译文进行转换，写明回退原因；不会把旧译文补回去。程序生成的 DuoSub 发布字幕不作为原版参考。

每份 第01集.zh-Hans.ass 另附 第01集.zh-Hans.reference.html，浏览器直接打开即可阅读，无需联网。报告列出导入原文、原版同字形底稿、当前工程文字、目标原配、纯自动转换、采用文字及最终 ASS 可见文字，并给出采用／回退原因、当前时间和来源 SHA-256；调时间不算改译。原版底稿缺失时以导入原文对照工程内的修改，并明确说明无法判断导入前的改动。

参考字幕和原文只读，功能不保存或改写工程，不影响日文正文和振假名。可以同时导出既有审议包；对照报告是本次自动导出的记录，与给大模型的审议包分别生成。取消后台生成不会写任何输出；个别对照报告生成或写入失败会在普通导出报告说明，成功的 ASS 仍保留。

字体检查

单独检查也在后台运行，显示「正在检查字体…」和「取消」，期间暂停编辑。取消或 Esc 停止测量，状态栏显示「已取消检查字体」，不显示结果窗口；正常结束后显示检查结果。进度窗口的 F1 打开本节。

工具 → 高级 → 私有功能默认勾选，选择记在本机。关闭后隐藏两个批量处理菜单项、「工具 → 高级 → 字体库位置…」以及缺字体结果中的字体库位置和「在资源管理器中显示」。

字体检查与导出前提示使用同一个结果窗口，逐项列出缺字体和受影响的行。字体库查到且文件还在时，点「在资源管理器中显示」打开并选中字体文件；查不到显示「字体库里也没有」。文件已不存在会提示「字体库里记的文件已经不在了：{路径}。可以用 assfonts 重新建库」。导出前可选择「仍然导出」或「取消」。

工具 → 高级 → 清除排版缓存删除当前工程的排版测量缓存，提示「排版缓存已清除，预览会重新测量。」。安装、替换字体或更新 ffmpeg 后，之后的排版测量会自动使用新结果；需要立即重测当前预览时也可以手动清除。后台测量会先停止，清除失败会说明原因。

导出时自动检查；也可以 工具 → 检查 → 字体（缺字体、缺字） 单独检查（不写文件）。用本机 libass 检查所有行：没装的字体、缺的字、任何字体都显示不了的字，列出受影响的行。只提示，不替换字体。

私有功能：工具 → 高级 → 字体库位置… 选择 assfonts 的 fonts.json，路径记在本机，不随工程。默认 %LOCALAPPDATA%\assfonts\fonts.json；缺字体时才读取并缓存。结果窗口提供文件定位，导出报告会在找到的缺字体旁显示「字体库里有：{path}」；库里有文件不代表本机已安装。字体检查不安装字体；批量处理可调用 assfonts 嵌入字体，需要刷新库时自行运行 assfonts.exe -b -f "fonts"。窗口的「帮助」和 F1 打开本节。

  3. 读音（包括拼音）和文字点「采用」；文字也可「改一下再采用…」，预填建议，修改后点「采用」。读音标为人工确认，文字只替换目标范围，其他字的来源、读音和 K 轴保留。繁体显示的简中行按显示文字定位，采用后转回简体保存。
  4. 「跳到这一组」选中对应组，回到主窗口手动处理；「试听」与 R 一样，播放本组前后余量。配对、说话人、人设和其他意见需手动处理后「标为已处理」。每条也可「不采用」。

组 ID 不对但文字唯一时显示「按文字找到（组 ID 不对）」；找不到显示「找不到原文（可能已经改过）」；多处命中显示「这一句里出现了几次，请选是哪一处」，必须先选位置；已与建议一致显示「已经改过了」。现在与原来不同时显示「现在的写法和意见里的“原来”不一样：现在」，不能直接采用。文字跨硬换行时显示「这条意见跨了换行，请跳到这一组手动改」，仅能跳转、标为已处理或不采用。

「采用所有读音意见」只处理能准确定位且当前读音等于原来的未处理意见，先确认「采用 n 条读音意见？」；冲突意见仍需逐条处理。单条采用和批量采用各自都是一步撤销。在审议窗口按 Ctrl+Z 可撤销；编辑框内仍撤销输入。

采用、不采用、已处理写入本集 review/answers.json，再次导回默认隐藏这些条目。撤销采用只恢复字幕，不删除处理记录。取消勾选「只看还没处理的」可查看记录及重新核对的当前状态；要重新修改请跳到该组手动编辑。

底部「没读懂的 n 行」可展开查看原文，不影响其他意见。一条都没读懂时提示「没有读到审议意见：回答里需要每条一行 JSON（审议包开头有格式说明）。」导入、改建议和审议窗口的「帮助」或 F1 打开本节。

批量处理一季（私有功能）

歌曲转写方式逐首选择，不跨季保存；Esc 关闭处理窗口，运行时先询问是否取消。

先用文件 → 新建工程…选择模板和字幕样式，之后照常引入角色。开启工具 → 高级 → 私有功能且已打开工程时，集菜单在「添加一集…」下面提供两个入口，共用一个窗口，按入口预选模式；未打开工程时不可用：

  • 集 → 自动导入整季…：视频、中文 ASS/SSA 和日文 SRT（或文件名含 ja 的 ASS）合并为双语字幕。
  • 集 → 自动导入整季（双语字幕）…：给已有双语 ASS/SSA 的日文对白加振假名；不做双语对齐，中文和日文按相同起止时间直接配对（允许 10 ms 误差），同时间多行按来源顺序；没有搭档或配对会交叉的行单独成组，不猜配对。振假名与可选采用建议时间照常处理。
  1. 选择「季目录」。按文件名前 7 个字符（例如 S01E001）识别集；视频支持 MKV、MP4，ZIP 等文件忽略。表格显示集、视频、中文字幕（第二种模式为双语字幕）、日文字幕和状态；第二种模式隐藏日文字幕列。
  2. 检查「就绪」「缺视频」「缺中文字幕」「缺日文字幕」和「有多个候选：{文件名}」。只有就绪的集会处理，其余写入跳过报告。
  3. 「歌曲」表按第一集就绪字幕识别 OP、ED、插曲，列出家族、样式、句数和建议，每首可选「转写并加振假名」／「原样保留」；使用 @ 字体并旋转 90°／270° 的竖排歌曲另有「转写为竖排并加振假名（右侧）」，默认选这一项，整季沿用，不跨季保存。自带振假名样式、特效绘图或平均每句超过 50 条特效时建议原样保留，其余建议转写；竖排歌曲可改选横排转写或原样保留。
  4. 整季导入当前工程。工程里已有同一集号时跳过，报告写「跳过（工程里已有这一集，未改动）」。对白样式和振假名大小沿用工程模板（JP.Ruby），不从来源字幕生成模板。
  5. 「调轴」选整季怎么对时间，按导入模式记在本机：
    • 「按视频的声音（推荐）」（默认）：每集和「时间轴 → 自动调轴（按视频音频）」一键相同，按人声找出整集或分段的偏差，两种语言一起挪；已经对得上或没有可信偏差时不改；没有视频的集不调。
    • 「按原声字幕的时间」（只有「中文字幕 + 日文字幕」模式）：对白用日文字幕文件里的时间，中文跟着，见统一两种语言的时间。只在日文字幕和视频同步时用。
    • 「按翻译字幕的时间（不另外调轴）」：合并本来就用中文字幕的时间，不再调整。双语模式里这一项叫「不调轴」。
    报告每集写一行「调轴：…」（挪了几组、最多差几秒，或没改的原因）。
  6. 「全季自动采用建议时间」默认关闭；开启时使用当前波形面板「建议时间」的提前／延后量，与 C 采用建议相同。受保护的人工时间保持。实测（少女革命 10 集，对照用户成品）：从字幕组中文轴出发，开始时间明显更准，结束时间变化不大；从已经较准的日文轴出发，整季采用后不会更准，还会改动一部分原本正确的时间。所以默认不勾，时间轴偏差大时再用。
  7. 「没有中文对照的叫喊和语气词不显示」默认勾选，选择记在本机，两种导入模式都适用。只有日文、整行均为叫喊／语气词（包括短叫声重复）的对白会隐藏，原文保留；有中文搭档、含汉字的台词、歌曲和特效不受影响。取消勾选可保留这些叫喊；导入后也可在编辑区的「未渲染」备注旁点「恢复显示」。
  8. 振假名大小跟工程模板走。「用 assfonts 嵌入字体」默认开启，显示 assfonts.exe 路径，可「更改…」或直接输入，位置记在本机。
  9. 点「开始」先保存工程和当前集的未保存修改，再后台处理。进度显示「第 {i}/{n} 集 {集}：{步骤}」，包括读取字幕、合并、读音、读取音频、按视频的声音调轴（或按原声字幕的时间调轴）、可选采用建议时间、导出、嵌入字体。窗口响应正常；此窗口打开时不能再启动另一批。
  10. 点「取消」在当前步骤结束后停止，已完成结果保留。运行时关闭窗口或按 Esc 会询问是否取消，等待当前步骤结束后显示报告。

输出在 {季目录}\DuoSub\{视频文件名去扩展名}.zh-ja.ass，同名加「 (2)」等编号，原视频和字幕不改。对白沿用工程模板，振假名让开中文。转写从卡拉 OK 模板的 Comment／karaoke 原歌词取整句与时间，中日同时间配对，以工程 OP／ED／插曲歌曲样式横排并加振假名；生成的 fx 不输出，来源保留可追溯。选择「转写为竖排并加振假名（右侧）」时，中日歌词沿用来源竖排样式和位置，日文振假名放在右侧，中文不加振假名；来源字体也参与嵌入。普通逐句歌词照歌曲规则导入。原样保留的歌曲特效与屏幕字不改。只有「中文字幕 + 日文字幕」模式下，日文字幕里带 ♪ 的歌词行与原样保留歌曲重叠超过一半时才隐藏（可恢复），转写歌词与中文歌曲正常配对；该歌词规则不隐藏对白，也不用于「已有中日双语」模式；没有中文的叫喊另按上面的勾选项隐藏。

结束后显示只读报告，同时写入输出文件夹的「批量处理报告-{时间}.txt」。报告列每集结果、跳过原因、歌曲处理方式、未配对行、待确认读音、缺字体和 assfonts 输出，并显示「隐藏没有中文的叫喊和语气词：{n} 行」。点「打开输出文件夹」查看结果。结束后集列表刷新出新加的集，当前打开的集和编辑会话保持。字体无法嵌入时保留普通导出并记录原因，来源已有内嵌字体尽量保留。

菜单项、处理窗口与报告窗口的「帮助」／F1打开本节。

精确对话轴（按台词对齐）

「时间轴 → 精确对话轴（按台词对齐）…」分析当前这一集：整集分离人声、两个识别模型，再按每句日文及这一处的读音对齐。分析在子进程中运行，可用「取消」停止，不会改动字幕；结果保存在工程缓存，重新打开本集时自动读取。依赖与自动 K 轴相同，缺少依赖时菜单灰掉。GPU 首次分析一集约 70–90 秒（约 1.5 分钟）；没有可用的显卡，CPU 上需要 15–20 分钟。之后可复用缓存。

打开「显示提示线」后，有有效对齐结果的对白组，人声开始／结束线显示对齐边界，白色建议线与 C 使用同一建议。图例显示「建议来源：按台词对齐」；无日文、对不上或文字／读音改过的句子，继续「按人声能量」判断。修改日文或读音后需重新分析该集；结果窗口会显示「文字改过，需要重新分析」。

「设置 ▾ → 建议提前量」照常生效。「按我调过的行（推荐）」只学本工程手调过的端（含既有人工确认规则），开始和结束各至少 20 个样本；结束与下一句间隔不超过 50 ms 的不参与。样本不足时用工程记住的对齐习惯，再不足时默认提前 165 ms、延后 250 ms。其他提前量模式沿用现有设置，图例显示实际数值和来源。

建议开始不吸附关键帧；建议结束在前 300／后 250 ms 内吸附最近的关键帧，不跨过下一句开始前 40 ms。关键帧尚未读取时先不吸附，读取后重算。建议开始不早于上一句当前结束后 40 ms；限制结束时，下一句有建议就用其建议开始，否则用当前开始。按 C 只采用当前组，一步撤销，来源仍为「采用建议」。

分析完成后打开「精确对话轴」结果窗口，显示已对齐、能量回退、两种识别不一致的句数以及提前／延后值。「整集采用…」打开逐端复查表；「关闭」关闭结果窗口。菜单、进度、结果窗口和采用对话框的 F1／帮助打开本节。

整集采用前逐端复查

表格每个有建议的对白组一行，列出时间、日文开头、当前开始→建议开始（差值）、当前结束→建议结束（差值）及标记。开始、结束各有勾选框；手调过的端默认不勾、显示灰色，但可以手动勾选，规则与提示线学习习惯相同。「两种识别不一致」提示需要试听；「文字改过，需要重新分析」的句子没有有效建议，只显示「文字改过」标记和当前时间，勾选框停用，不列入可采用行。

勾选「只显示相差超过 [100] ms 的」可筛选任一端相差超过阈值的行（默认阈值 100 ms，可修改）；隐藏行保留勾选状态，仍会随「采用勾选的」一起采用。打开表格时，用采用前的当前时间、当前提前／延后值和已加载关键帧一次算出全部建议；采用过程中不逐行重算。采用不会让原来不重叠的相邻可见对白／歌曲组新增重叠：改动的一端退让，能留 40 毫秒就留，否则紧贴；两端都改时前一句的结束退让，退不了的一端不采用。原有重叠保持。「采用勾选的」只改勾选端，记录为「采用建议」，整次可用 Ctrl+Z 一步撤销「精确对话轴（整集）」，撤销／重做同时恢复时间来源。「取消」或 Esc 不改时间。

常见问题

第一行中文不显示

以前的原因：字幕文件第一个事件时长为 0 时，播放器把整条字幕当成“时长未知”，把紧接着的行截掉。现在没有显示时间的行都写成注释行，列表里标“不显示”，改好时间就会显示。

输入法组字跑到别的框里

读音弹窗、就地编辑框、对话框都是能获得焦点的窗口，Windows 输入法在里面正常组字。如果还遇到，请记下是哪个窗口。

字体和别的播放器显示不一样

预览和导出都用 libass。振假名在 PotPlayer 和 Plex 里的折行可能不同，字体由你决定；程序只提示缺字体、缺字。

改动会不会动到原来的字幕文件？

不会。工程里有原字幕的只读副本，所有修改都在工程文档里，导出写新文件。
